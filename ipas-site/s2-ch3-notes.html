📐 離散量度 Dispersion

描述資料「波動幅度」

  • Variance σ²
    偏離平均的平方均值
    σ² = Σ(xᵢ − μ)² / N
  • SD σ
    變異數的平方根，單位與原資料相同
  • Range
    Max − Min，易受極端值影響
  • IQR
    Q3 − Q1 中間50%範圍，抗離群值
📦 箱形圖 Box Plot

上/下鬚 = Q3 ± 1.5×IQR　超出者為離群值

〽️ 分佈形狀 Shape
偏度 Skewness
正偏態 > 0 右尾長 負偏態 < 0 左尾長 ≈ 0 對稱

正偏常見：收入、房價（少數高值拉高平均）

峰度 Kurtosis
高峰 > 3 Leptokurtic 中峰 ≈ 3 Mesokurtic 扁平 < 3 Platykurtic

高峰 → 更多極端值，機器學習預測需特別留意

3.3
假設檢定與統計推論
🔬 假設檢定流程
Step by Step
①設定 H₀虛無假設 vs H₁對立假設
②設顯著水準 α（通常 0.05 或 0.01）
③蒐集樣本、計算檢定統計量
④計算 p-value
⑤p < α → 拒絕 H₀；否則不拒絕
p-value 意義

假設 H₀ 成立，觀察到「這麼極端或更極端」資料的機率。p 值越小 → 越有力反對 H₀

⚠️ 兩類決策錯誤
型一錯誤 α
H₀ 實際成立
→ 卻拒絕它
= False Positive
冤枉好人
型二錯誤 β
H₀ 實際錯誤
→ 卻不拒絕它
= False Negative
放走壞人
檢定力 Power = 1 − β
正確拒絕 H₀ 的能力 → 越高越好
🧰 常見檢定方法
方法 適用情境
z 檢定 大樣本或已知σ，母體均值比較
t 檢定 小樣本、σ未知；單/雙樣本、配對
χ² 檢定 類別資料獨立性、適合度
ANOVA 三組以上均值比較（F 統計量）
📏 信賴區間 Confidence Interval

估計母體參數所在的範圍，具某程度的信心水準

CI = x̄ ± z·(σ/√n)
常用信賴水準
90% CI → z = 1.645 95% CI → z = 1.960 99% CI → z = 2.576

信賴水準↑ → 區間越寬；樣本數↑ → 區間越窄

單尾 vs 雙尾檢定
▶ 雙尾：μ ≠ 某值（方向不確定）
▶ 單尾：μ > 或 < 某值（方向明確）
