EDA 看兩件事

特徵關聯性：特徵與特徵高度相關 → 冗餘特徵；特徵與預測目標高度相關 → 重要特徵。資料分布：看 min、max、mean、std，判斷數值範圍是否差太多。

為什麼要正規化

TAX（數百）與 NOX（小於 1）尺度差很多。用梯度下降的模型（神經網路）和對距離敏感的模型，要先把特徵壓到相近範圍，例如 MinMaxScaler 壓到 0～1。

工具定位

四套工具各自擅長什麼

工具定位典型寫法輸出重點適合情境
Statsmodels傳統統計建模sm.add_constant(X) → sm.OLS(y, X).fit()／sm.Logitsummary()：係數、標準誤、p 值、信賴區間、R²要「解釋」變數影響、做假設檢定、寫研究報告
scikit-learn經典機器學習model.fit(X, y) → predict／score；train_test_split、MinMaxScaler預測值與評估指標，API 一致表格資料、快速建立基準模型、前處理與評估流程
Keras（TensorFlow 後端）高階深度學習 APISequential([Dense…]) → compile(loss, optimizer) → fit(epochs, batch_size) → evaluate每個 epoch 的 loss／metrics用少量程式碼快速搭出標準神經網路
PyTorch彈性深度學習框架繼承 nn.Module 寫 forward；自己寫訓練迴圈：zero_grad → backward → steptensor 與梯度（grad_fn）研究、客製化模型結構、需要掌控每一步訓練細節

Statsmodels 要自己加截距

sm.add_constant 會加一欄全為 1 的 const。scikit-learn 的 LinearRegression 預設 fit_intercept=True，不必手動加。

Keras 的三步：建、編、訓

Sequential 建模型 → compile 指定損失函數與優化器（影片用 "mae"、"sgd"）→ fit 指定 epochs 與 batch_size。

PyTorch 的訓練迴圈

每個批次：前向計算 → 算 loss → optimizer.zero_grad() 清掉舊梯度 → loss.backward() 反向傳播 → optimizer.step() 更新權重。

資料格式要對齊工具

PyTorch 要把 NumPy 轉成 torch.tensor(…, dtype=torch.float32)；Keras 多分類用 to_categorical 轉 One-hot；預測後再用 argmax 轉回類別。

PyTorch 22:40

Python｜影片程式碼
import torch
class Model(torch.nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(Model, self).__init__()
        self.hidden1 = torch.nn.Linear(input_size, hidden_size)
        self.hidden2 = torch.nn.Linear(hidden_size, hidden_size)
        self.predict = torch.nn.Linear(hidden_size, output_size)
    def forward(self, x):
        output1 = self.hidden1(x)
        output2 = self.hidden2(output1)
        return self.predict(output2)

model = Model(X_test.shape[1], 32, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)
loss_func = torch.nn.L1Loss()                 # L1 = MAE
x_data = torch.tensor(X_train, dtype=torch.float32)   # [404, 13]
y_data = torch.tensor(y_train, dtype=torch.float32)   # [404, 1]
for t in range(100):                          # 100 個 epoch
    for i in range(0, len(x_data), 16):       # 手動切 batch = 16
        prediction = model(x_data[i:i+16])
        loss = loss_func(prediction, y_data[i:i+16])
        optimizer.zero_grad(); loss.backward(); optimizer.step()
# 測試 MAE 0.0721

Keras 和 PyTorch 這兩個版本的隱藏層都沒有啟用函數，多層線性疊起來仍然是線性模型，所以三者的 MAE 才會那麼接近。這是很好的觀念題，詳見「實作陷阱」。

實測：這份資料能用 Statsmodels 做邏輯迴歸嗎？

我用同樣 10 筆資料、同樣的切法重跑（statsmodels 0.15、scikit-learn 1.9）：

影片寫法（const + France + Germany + Spain）設計矩陣秩 = 5，但有 6 欄 → Logit：Singular matrix 去掉一個國家虛擬變數（避免虛擬變數陷阱）→ 仍然 Singular matrix（7 筆資料估 5 個參數） scikit-learn LogisticRegression（預設 L2 正則化）→ 可以訓練，但 3 筆測試預測 [0, 0, 0]，實際 [1, 0, 1] sm.OLS 薪資迴歸：R² 0.896，但殘差自由度只有 2，所有係數 p 值都 > 0.15

這解釋了影片為什麼把 sm.Logit 註解掉：資料太少、加上 const 與三個虛擬變數完全共線，最大概似估計無法求解。Keras 在這份資料上訓練 Accuracy 達到 1.0，也只代表 7 筆資料被背下來，不代表模型有用。

Python｜改良版
class Model(torch.nn.Module):
    def __init__(self, n_in, n_hidden, n_class):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(n_in, n_hidden), torch.nn.ReLU(),      # 加上啟用函數
            torch.nn.Linear(n_hidden, n_hidden), torch.nn.ReLU(),
            torch.nn.Linear(n_hidden, n_class))                   # 直接輸出 logits，不做 softmax
    def forward(self, x):
        return self.net(x)

loss_func = torch.nn.CrossEntropyLoss()          # 標籤用整數類別（torch.long），不必轉 One-hot
y_data = torch.tensor(y_train, dtype=torch.long)
pred_class = model(x_test).argmax(dim=1)         # 推論時取最大值

觀眾在直播中問：「兩層是 test_size=0.2，那三層是不是設成 0.3？」兩者無關：隱藏層數是模型結構的超參數，test_size 是切多少比例資料當測試集。

選擇工具

什麼情況該用哪套工具

  1. 要解釋「哪個變數影響多少、是否顯著」（例如政策評估、行銷歸因報告）→ Statsmodels 的 OLS／Logit，看係數、p 值、信賴區間。
  2. 表格資料、要快速做出可比較的基準模型 → scikit-learn。前處理、切分、交叉驗證、評估指標都有一致的 API，可用 Pipeline 防止洩漏。
  3. 需要神經網路，但結構是標準的全連接、CNN、RNN → Keras，幾行就能完成建模、編譯、訓練。
  4. 需要客製化結構、特殊損失函數，或要掌控訓練迴圈每一步（研究、生成式模型、微調大型模型）→ PyTorch。
  5. 先簡單後複雜：先用 scikit-learn 建立基準，確認深度學習真的有明顯提升，再投入較高的開發與運算成本。
