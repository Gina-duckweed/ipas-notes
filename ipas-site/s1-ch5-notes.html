Data Preparation & Model Selection
資料清理技術
遺漏值：均值/中位數填補（Imputation）、前後向填補（Forward/Backward Fill）、線性插補。異常值：Z-score、IQR、Isolation Forest、LOF。重複值：drop_duplicates。
特徵工程
編碼：One-hot / Label / Target Encoding。標準化：Min-Max（0-1）、Z-score 標準化。特徵選擇：Information Gain、Pearson 相關係數、L1 正則化（Lasso）。降維：PCA（保留最大變異方向）、t-SNE/UMAP（視覺化）。
AutoML
自動特徵工程與模型選擇。代表工具：Google AutoML、H2O.ai、AutoKeras、TPOT。自動執行特徵創建、篩選、超參數調優，降低技術門檻。

5.2
AI 系統集成與部署
AI System Integration & Deployment
系統集成
資料管線：Data Pipeline（擷取→轉換→清理→入庫）。企業系統整合：ERP/CRM/POS/MES 接軌 AI 模型輸出。API 封裝：RESTful API / gRPC / Webhooks，提供推論服務。安全：OAuth2/JWT 身份驗證，API Gateway 流量控管。
MLOps CI/CD
CI（持續整合）：程式碼/資料變動觸發自動訓練+測試。CD（持續部署）：通過閾值後自動部署至生產環境。版本管理：MLflow（實驗追蹤）、DVC（資料版本控制）。
監控與成效追蹤
偵測 Model Drift / Data Drift；KPI 三層：系統層（延遲/吞吐量）、應用層（準確率/F1）、業務層（ROI/轉換率）。觸發再訓練：設定效能下降閾值（如準確率降5%）啟動 Retraining Pipeline。

主要 ML 模型任務類型

迴歸（Regression）
監督式・連續輸出
Linear / Decision Tree / Random Forest / Gradient Boosting。應用：銷售預測、房價預測。
分類（Classification）
監督式・離散輸出
Logistic / SVM / KNN / Random Forest / Gradient Boosting。應用：垃圾郵件、疾病診斷。
聚類（Clustering）
非監督式・分群
K-means / DBSCAN / Hierarchical。應用：顧客分群、異常偵測。PCA 降維。
深度學習（DL）
CNN / RNN / Transformer
CNN 影像分類；LSTM 時序資料；Transformer NLP 主流；PPO 強化學習。
生成模型
GAN / VAE / Diffusion
GAN 對抗生成（Mode Collapse風險）；VAE 潛在空間平滑；Diffusion 品質最高。

AI 系統部署模式

公有雲部署
AWS / Azure / GCP
彈性擴充、按量付費、全球節點。挑戰：資料隱私合規（GDPR）、供應商鎖定風險。
私有雲部署
OpenStack / VMware
資料不外流、高安全合規性。適合：政府、金融、醫療等嚴格管制行業。成本高。
邊緣運算
Edge Computing
在終端裝置（IoT/手機/車載）本地推論，低延遲、保護隱私。挑戰：資源有限、更新複雜。
混合部署
Hybrid Deployment
雲端訓練 + 邊緣推論，兼顧算力與延遲。需設計資料同步與一致性機制，整合難度高。

⭐ 考試重點

PCA 保留最大方差方向降維；t-SNE/UMAP 用於視覺化，不適合後續建模
迴歸預測連續值；分類輸出離散標籤；聚類無標注自動分群
Docker 容器確保跨平台環境一致性；Kubernetes 負責容器編排與自動擴縮
Blue-Green Deployment：兩套環境切換，零停機更新；Canary：逐步灰度發布
MLflow 追蹤實驗參數與模型版本；DVC 管理訓練資料集版本
邊緣運算：推論在終端本地執行，降低延遲和頻寬消耗，適合 IoT 即時場景
