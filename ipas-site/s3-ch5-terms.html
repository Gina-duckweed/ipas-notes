5.1 數據準備與特徵工程
Missing Value Imputation
缺失值填補
針對資料集中遺漏的欄位值，用適當策略補齊的技術。常見方法：均值/中位數填補（數值型）、眾數填補（類別型）、KNN 或迴歸模型預測填補、缺失指標法（新增 is_missing 欄位）。
🔍 應用場景醫療紀錄部分欄位空白，以同年齡患者均值補齊血壓值。
⚡ 考試提示刪除法適用於缺失比例低（<5%）；缺失指標法可保留缺失本身的資訊。
Outlier Detection
異常值偵測
識別資料中偏離整體分佈的極端值。方法包含：Z-score（|z|>3）、IQR 法（Q1−1.5×IQR ~ Q3+1.5×IQR）、Isolation Forest（路徑短＝異常）、LOF 局部離群因子（密度對比）。
🔍 應用場景信用卡交易中，突然大額消費以 Isolation Forest 標記為潛在詐欺。
⚡ 考試提示Z-score 假設常態分佈；IQR 法對非常態更穩健。
Interquartile Range Method
IQR 法
IQR
以四分位距（Q3−Q1）定義正常值範圍的異常偵測方法。落在 [Q1−1.5×IQR, Q3+1.5×IQR] 區間外的值視為異常。對偏態分佈、含極端值的資料比 Z-score 更穩健。
🔍 應用場景薪資資料右偏，用 IQR 法濾除少數超高薪資的干擾。
⚡ 考試提示IQR = Q3 − Q1；箱形圖（Box Plot）就是 IQR 法的視覺化呈現。
Isolation Forest
孤立森林
以隨機切割（Random Partitioning）偵測異常點的非監督式算法。異常點因特徵值極端，隨機切割幾次就能被「孤立」，平均路徑長度短；正常點需要更多切割才能孤立，路徑長。
🔍 應用場景網路流量異常偵測：攻擊封包特徵極端，孤立森林快速標記。
⚡ 考試提示無需距離計算，高維資料表現優；路徑越短＝異常分數越高。
Feature Selection
特徵選擇
從原始特徵中挑選對模型最有貢獻的子集，去除冗餘與無關特徵，降低維度、防止過擬合、加快訓練。三大類：Filter（統計獨立評估）、Wrapper（以模型反饋搜尋）、Embedded（訓練時自動選擇）。
🔍 應用場景房價預測資料有 100 個特徵，用 RFE 保留最重要的 20 個。
⚡ 考試提示Filter 最快但忽略特徵互動；Wrapper 最準但計算成本高。
Principal Component Analysis
主成分分析
PCA
線性降維方法，將原始特徵投影到最大化變異的新正交軸（主成分）。非監督式，不需標籤。透過 SVD 分解協方差矩陣獲得主成分方向，保留前 k 個主成分以捕捉大部分資訊。
🔍 應用場景人臉辨識前，用 PCA 將 10,000 維像素壓縮成 200 個主臉（Eigenfaces）。
⚡ 考試提示PCA 無監督、線性；LDA 有監督、線性；t-SNE 無監督、非線性（僅視覺化）。
Linear Discriminant Analysis
線性判別分析
LDA
監督式線性降維方法，目標是最大化類別間距離（Between-class variance）、最小化類別內變異（Within-class variance），同時完成降維與分類。需要類別標籤，適合分類前處理。
🔍 應用場景多類別鳶尾花資料集降維，使各類別在低維空間最易分開。
⚡ 考試提示LDA 最多降至 C−1 維（C 為類別數）；假設各類別高斯分佈且共享協方差矩陣。
t-SNE / UMAP
非線性降維（視覺化）
t-SNE（t分佈隨機鄰域嵌入）與 UMAP 皆為非線性降維技術，將高維資料嵌入 2D/3D 以利視覺化。t-SNE 保留局部結構但不保全局；UMAP 更快且更好保留全局結構，可用於預處理。
🔍 應用場景MNIST 手寫數字 784 維特徵以 t-SNE 降至 2D，可見各數字明顯聚類。
⚡ 考試提示t-SNE 不能用於新資料推論（無法 transform）；UMAP 可，且速度更快。
Min-Max Normalization
Min-Max 正規化
將數值特徵線性縮放到固定區間（通常 [0,1]）的特徵縮放方法。公式：x' = (x−min)/(max−min)。對異常值敏感（極值會主導範圍），適用於不含極端值的資料。
🔍 應用場景影像像素值 [0,255] 縮放為 [0,1] 供神經網路輸入。
⚡ 考試提示vs Z-score：Min-Max 輸出範圍固定；Z-score 輸出均值0、標準差1，對異常值更穩健。
Z-score Standardization
Z-score 標準化
將特徵轉換為均值 0、標準差 1 的標準正態分佈。公式：z = (x−μ)/σ。比 Min-Max 更抗異常值。適用於假設特徵近似常態的演算法（如 SVM、線性回歸、PCA、LDA）。
🔍 應用場景SVM 訓練前對所有特徵做 Z-score，避免大尺度特徵主導支持向量。
⚡ 考試提示Robust Scaler 以 IQR 縮放，對含離群值的資料比 Z-score 更佳。
One-hot Encoding
One-hot 編碼
將類別變數轉為二元稀疏向量，每個類別對應一個維度，該維度為 1 其餘為 0。避免整數編碼引入假的大小關係。缺點：高基數（high cardinality）類別會產生大量稀疏維度（維度災難）。
🔍 應用場景城市欄位有台北/台中/高雄，轉為 [1,0,0]、[0,1,0]、[0,0,1] 三個特徵。
⚡ 考試提示有序類別（小/中/大）用 Label Encoding；無序類別用 One-hot；高基數用 Target Encoding。
SMOTE
合成少數類過採樣技術
SMOTE
Synthetic Minority Over-sampling Technique。在少數類樣本之間「插值」合成新樣本，而非直接複製，解決類別不平衡問題。公式：x_new = x + δ·(x_neighbor − x)，δ∈[0,1]。
🔍 應用場景詐欺偵測資料正常:詐欺＝99:1，用 SMOTE 合成詐欺樣本至 80:20。
⚡ 考試提示SMOTE 合成新樣本（非複製）；Oversampling 是直接複製；兩者皆增加少數類數量。
5.2 模型選擇與架構設計
Bias-Variance Tradeoff
偏差－變異權衡
模型泛化誤差 = 偏差² + 變異 + 不可消除雜訊。高偏差（欠擬合）：模型太簡單，訓練與測試誤差均高；高變異（過擬合）：訓練誤差低但測試誤差高。需在兩者間找平衡點。
🔍 應用場景決策樹深度越大，偏差降低但變異增高；用剪枝或 Random Forest 集成降低變異。
⚡ 考試提示加正則化→降低變異；增加特徵/模型複雜度→降低偏差；取得平衡是調參核心。
5.3 訓練評估驗證
K-fold Cross Validation
K-fold 交叉驗證
將資料分成 k 等份，輪流以其中一份為驗證集、其餘為訓練集，共訓練 k 次，取平均誤差作為模型泛化估計。能充分利用有限資料，比單一 Train/Test Split 更穩健。
🔍 應用場景小型醫療資料集，5-fold CV 估計模型性能，確保每筆樣本都被驗證一次。
⚡ 考試提示k 越大：偏差越低但計算越慢；k=N 即 LOOCV（計算成本最高）。
Leave-One-Out Cross Validation
留一交叉驗證
LOOCV
K-fold 的特例，k = N（總樣本數）。每次只留一筆作驗證集，其餘 N-1 筆訓練。誤差估計幾乎無偏，但計算代價極高（需訓練 N 次模型），適用於極小資料集。
🔍 應用場景罕見疾病研究，樣本僅 30 筆，用 LOOCV 充分利用每筆樣本。
⚡ 考試提示LOOCV 低偏差但高變異（各折訓練集幾乎相同，結果相關性高）；計算成本隨 N 線性增加。
Precision
精確率（查準率）
在所有被模型預測為正類的樣本中，真正為正類的比例。公式：Precision = TP / (TP + FP)。當誤報（FP）代價高時（如垃圾郵件過濾），應優先最大化 Precision。
🔍 應用場景推薦系統：推薦給用戶的商品中，真正喜歡的比例 → 追求高 Precision。
⚡ 考試提示Precision 高 → 誤報少；Recall 高 → 漏報少；兩者往往成反比，F1 取調和均值。
Recall（Sensitivity）
召回率（敏感度）
在所有真實正類樣本中，被模型正確預測到的比例。公式：Recall = TP / (TP + FN)。當漏報（FN）代價高時（如癌症篩查、詐欺偵測），應優先最大化 Recall。
🔍 應用場景癌症篩查：真正患癌者中，被系統正確偵測出的比例 → 寧可多報也不漏報。
⚡ 考試提示降低分類門檻 → Recall↑、Precision↓；提高門檻 → Precision↑、Recall↓。
F1-Score
F1 分數
Precision 與 Recall 的調和均值，綜合兩者表現。公式：F1 = 2×P×R / (P+R)。在類別不平衡資料中比 Accuracy 更具參考價值，適合詐欺偵測、罕見疾病診斷等場景。
🔍 應用場景詐欺偵測：正負樣本 1:99，Accuracy 99% 沒意義，F1 才能衡量少數類表現。
⚡ 考試提示F1 是調和均值，對 P/R 的低值更敏感；Fβ 可調整 P/R 的相對重要性。
ROC-AUC
ROC 曲線下面積
AUC
ROC 曲線以 TPR（Recall）為 Y 軸、FPR 為 X 軸，AUC 為該曲線下面積（0–1）。AUC=1 完美；AUC=0.5 等同隨機猜測。對類別不平衡資料仍有意義，適合比較不同模型整體分類能力。
🔍 應用場景比較邏輯回歸與隨機森林在信用違約預測的表現，以 AUC 為統一標準。
⚡ 考試提示AUC 與分類門檻無關，衡量整體排名能力；PR-AUC 在極度不平衡時比 ROC-AUC 更具區分力。
5.4 模型調整與優化
Early Stopping
早停法
在訓練過程中監控驗證集損失，當驗證損失停止下降（或開始上升）時提前終止訓練，防止過擬合。是一種隱性正則化，無需修改損失函數，配合 Patience 參數使用。
🔍 應用場景深度神經網路訓練，設 patience=10，驗證損失連 10 個 epoch 不降即停止。
⚡ 考試提示Early Stopping 是正則化技術，與 Dropout、L1/L2 並列，可同時使用。
L1 Regularization (Lasso)
L1 正則化
Lasso
在損失函數中加入權重絕對值之和的懲罰項（λΣ|wᵢ|）。使部分係數精確歸零，自動進行特徵選擇，產生稀疏模型。適合特徵數量多且多數無關的場景。
🔍 應用場景基因表達資料有 20,000 個特徵，Lasso 自動保留與疾病相關的少數基因。
⚡ 考試提示L1→稀疏/特徵選擇；L2→係數縮小但不歸零；Elastic Net＝L1+L2 兼顧兩者。
L2 Regularization (Ridge)
L2 正則化
Ridge
在損失函數中加入權重平方和的懲罰項（λΣwᵢ²）。使所有係數均勻縮小趨近於零，但不精確歸零。防止任一特徵過度主導模型，適合特徵間高度相關（多共線性）的資料。
🔍 應用場景房價預測模型中面積、房間數高度相關，Ridge 防止某特徵係數過大。
⚡ 考試提示Ridge 不做特徵選擇；需保留全部特徵但防過擬合時首選；計算上比 Lasso 更穩定。
Dropout
隨機失活
深度學習正則化技術。訓練時每個 epoch 以概率 p（通常 0.5）隨機將某些神經元輸出設為 0，迫使模型學習冗餘表示、不依賴特定神經元。推論時不丟棄，但輸出乘以 (1−p) 縮放。
🔍 應用場景CNN 全連接層加入 Dropout(0.5)，顯著降低測試集誤差，防止過擬合。
⚡ 考試提示Dropout 等效於訓練多個不同子網路的集成；推論時輸出需乘以保留率 (1−p)。
Adam Optimizer
Adam 優化器
Adam
結合 Momentum（一階動量）與 RMSProp（二階動量）的自適應學習率優化器。分別估計梯度的一階矩（均值）和二階矩（方差），為每個參數自動調整學習率。目前深度學習首選預設優化器。
🔍 應用場景訓練 Transformer 語言模型，Adam with weight decay（AdamW）為標配優化器。
⚡ 考試提示Adam = Momentum + RMSProp；AdamW 加入 Weight Decay 解決 L2 正則化等效問題。
Oversampling / SMOTE
過採樣（重取樣）
解決類別不平衡的重取樣策略。Oversampling 直接複製少數類樣本；SMOTE 在少數類樣本間插值合成新樣本（避免過擬合到已存在樣本）；Undersampling 則刪減多數類樣本。
🔍 應用場景正負樣本 1:100，使用 SMOTE 使比例接近 1:3，再配合 Class Weight 訓練。
⚡ 考試提示SMOTE 合成新樣本；Oversampling 複製；兩者皆增加少數類數量；Undersampling 丟失資料。
Knowledge Distillation
知識蒸餾
模型壓縮技術。以大型「教師模型（Teacher）」的輸出軟標籤（類別機率分佈）訓練小型「學生模型（Student）」，使學生模型在推論效能接近教師模型的同時大幅降低計算量與記憶體。
🔍 應用場景GPT-4 為教師，蒸餾出可在手機端執行的 DistilBERT 學生模型。
⚡ 考試提示軟標籤（soft labels）比 One-hot 硬標籤包含更多類別間關係資訊，是蒸餾的核心。
Model Pruning
模型剪枝
刪除神經網路中對輸出貢獻微小的權重或神經元的模型壓縮方法。可分為：非結構化剪枝（移除個別權重，產生稀疏矩陣）與結構化剪枝（移除整個神經元/卷積核，模型直接縮小）。
🔍 應用場景將 ResNet-50 結構化剪枝 40%，推論速度提升 1.5 倍，準確率下降不到 1%。
⚡ 考試提示剪枝後通常需 Fine-tuning 恢復精度；結構化剪枝可直接加速，非結構化需特殊稀疏計算硬體。
Quantization
模型量化
將模型權重和/或激活值從高精度浮點數（FP32）轉換為低精度表示（INT8、INT4）的壓縮技術。可大幅降低模型大小（4×）與推論延遲，代價是極小精度損失，適合邊緣裝置部署。
🔍 應用場景LLM 以 4-bit 量化在消費級 GPU 上執行，記憶體需求從 80GB 降至 8GB。
⚡ 考試提示Post-Training Quantization（PTQ）無需重新訓練；QAT（量化感知訓練）精度更高。
Mixed Precision Training
混合精度訓練
FP16+FP32
訓練時同時使用 FP16（半精度）與 FP32（全精度）。前向傳播和梯度計算用 FP16（速度快、記憶體省），梯度更新用 FP32（防止數值下溢）。配合「損失縮放」技術防止梯度消失。
🔍 應用場景在 A100 GPU 訓練大型語言模型，啟用 AMP 後速度提升 2-3 倍，顯存減半。
⚡ 考試提示FP16 速度快但數值範圍小，需 Loss Scaling 防梯度下溢；PyTorch AMP 自動處理。
Singular Value Decomposition
奇異值分解
SVD
矩陣分解方法，將矩陣 A 分解為 A = UΣVᵀ。U、V 為正交矩陣，Σ 為奇異值對角矩陣。取前 k 個奇異值可得最佳低秩近似（PCA 的數值實現基礎），廣泛用於推薦系統（潛在語義分析）。
🔍 應用場景Netflix 電影推薦：用戶-電影評分矩陣 SVD 分解，發現潛在偏好因子。
⚡ 考試提示PCA 等同於對協方差矩陣做 SVD；SVD 也是 NLP 中 LSA（潛在語義分析）的核心。
