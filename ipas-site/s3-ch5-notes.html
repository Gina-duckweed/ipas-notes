5.1
缺失值處理 & 異常值偵測
缺失值處理策略
  • 刪除法：列刪除（資料量充足）
  • 均值／中位數填補：數值型快速填補
  • 預測模型填補：回歸、KNN 推估缺失值
  • 缺失指標法：新增 is_missing 二元欄位
異常值偵測方法
  • Z-score：|z|>3 視為異常；常態分佈假設
  • IQR 法：Q1−1.5×IQR ～ Q3+1.5×IQR
  • Isolation Forest：隨機分割，異常者路徑短
  • LOF：局部離群因子；密度比較法

5.1
特徵選擇 & 降維
特徵選擇三大方法
  • Filter 方法：相關係數、卡方、互資訊；與模型無關
  • Wrapper 方法：RFE 遞迴特徵消除；模型導向搜尋
  • Embedded 方法：Lasso 正則化、決策樹特徵重要性
降維技術
  • PCA：線性、最大化變異，非監督式
  • LDA：線性、最大化類別間距，監督式
  • t-SNE / UMAP：非線性；視覺化高維資料
  • SVD：奇異值分解；矩陣低秩近似

特徵轉換、編碼 & 資料增強
特徵縮放 / 轉換
  • Min-Max 正規化：縮放到 [0,1]；對極值敏感
  • Z-score 標準化：均值0、標準差1
  • Robust Scaling：用 IQR 縮放；抗異常值
  • Log Transform：處理右偏分佈；Box-Cox 更通用
類別特徵編碼
  • Label Encoding：整數編碼；有序類別適用
  • One-hot Encoding：二元向量；無序類別
  • Target Encoding：以目標均值替代；防過擬合需交叉驗證
資料增強（解決資料不足）

5.2
模型選擇與架構設計
選擇模型的四維考量
  • 任務類型：分類→SVM/樹/DNN；迴歸→線性/樹/MLP；生成→GAN/VAE
  • 資料規模：小資料→簡單模型+正則化；大資料→深度學習
  • 解釋性需求：醫療/金融→決策樹、線性模型；精度優先→黑盒可
  • 資源限制：Edge 部署→輕量模型；雲端→大模型
偏差－變異權衡
高偏差
↔
高變異
  • 欠擬合（高偏差）：模型太簡單，訓練誤差大
  • 過擬合（高變異）：訓練好但測試差，需正則化
  • 最佳：偏差與變異均低，泛化能力強
5.3
交叉驗證策略
K-fold 家族
  • K-fold CV：k 等份輪流做驗證集，估計泛化誤差
  • Stratified K-fold：各折保持類別比例；不平衡資料首選
  • LOOCV：k=N，變異大但無偏；小資料集適用
  • Repeated K-fold：多次 shuffle 後 K-fold，更穩健估計
批次訓練方式
  • Batch GD：全資料一次更新；穩定但慢
  • SGD：單樣本更新；快速但噪聲大
  • Mini-batch：折中，通常 32–256；GPU 最佳化

超參數 & 優化器
常見超參數類型
  • 學習率 (lr)：步伐大小；過大發散，過小收斂慢
  • 批次大小 (batch size)：影響梯度估計穩定性與訓練速度
  • 網路深度／寬度：層數、神經元數；容量與計算成本
  • 正則化係數 λ：L1／L2 懲罰強度

5.4
正則化技術 & 模型壓縮加速
正則化防止過擬合
  • L1 正則化 (Lasso)：稀疏化權重，適合特徵選擇，部分係數歸零
  • L2 正則化 (Ridge)：縮小所有權重，防止任一特徵支配
  • Elastic Net：L1+L2 組合；兼顧稀疏與穩定
  • Dropout：訓練時隨機丟棄神經元（p=0.5）；強迫模型魯棒
  • Early Stopping：驗證損失不再下降即停止，避免過擬合
資料增強與重取樣（類別不平衡）
Oversampling（複製少數類） SMOTE（合成少數類樣本） Undersampling（縮減多數類） Class Weighting
模型壓縮加速（推論效能）
  • 知識蒸餾：大模型→小模型，保留「軟標籤」知識
  • 模型剪枝：移除接近0的權重或神經元
  • 量化：FP32→INT8，降低記憶體與計算量
  • 混合精度訓練：FP16 前向傳播＋FP32 更新，速度↑精度↑
📐 分類評估公式
精確率：P = TP/(TP+FP)
召回率：R = TP/(TP+FN)
F1-Score：2PR/(P+R)
📐 迴歸評估公式
MSE：Σ(yᵢ−ŷᵢ)² / n
MAE：Σ|yᵢ−ŷᵢ| / n
R²：1 − SS_res/SS_tot
📐 正則化懲罰項
L1 (Lasso)：λ Σ|wᵢ|
L2 (Ridge)：λ Σwᵢ²
Elastic Net：α·L1 + (1−α)·L2
📐 SMOTE 合成
新樣本：x_new = x + δ·(xₙ−x)
IQR 異常：[Q1−1.5×IQR, Q3+1.5×IQR]
Z-score：z = (x−μ)/σ
⚡ 考試高頻考點 Exam Focus
Q：SMOTE 解決什麼問題？
A：類別不平衡，合成少數類的人工樣本（非複製），提升少數類分類能力
Q：L1 vs L2 正則化差異？
A：L1 使部分係數歸零（特徵選擇）；L2 縮小所有係數但不歸零（較穩定）
Q：Stratified K-fold 適用情境？
A：類別不平衡的分類任務；確保每折類別分佈一致，結果更可靠
Q：Dropout 作用原理？
A：訓練時隨機丟棄神經元，強迫學習冗餘特徵，推論時不丟棄
Q：知識蒸餾的「軟標籤」？
A：大模型輸出的機率分佈（含類別間關係）比 One-hot 標籤含更多知識
Q：Adam 優化器優點？
A：結合 Momentum（一階矩）+ RMSProp（二階矩），自適應學習率，收斂快
