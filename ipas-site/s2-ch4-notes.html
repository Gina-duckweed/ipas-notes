4.1 數據收集與清理
資料來源類型 Data Sources
📡
感測器 / IoT
高頻、時間序列；MQTT、Kafka 串流；邊緣運算預處理
📋
系統日誌 / 行為紀錄
Web Log、點擊軌跡；Flume、Logstash、NiFi 傳輸
🔌
API / 外部資料交換
RESTful API；JSON/XML；ETL 整合 (Airflow、Talend)
🕷️
網路爬蟲 / 開放平台
Scrapy、BeautifulSoup；data.gov、Kaggle 資料集
🏭
企業內部系統
ERP / CRM / POS；SQL 批次匯出；Snowflake、BigQuery
更新頻率：即時/批次 格式轉換需求 資料品質 即時性要求 隱私與合規 GDPR/CCPA
資料品質問題類型
缺失值
Missing Data
欄位空值；MCAR / MAR / MNAR 三類缺失
→ 填補 (均值/KNN) / 刪除 / 保留
異常值
Outliers
極端偏離分佈；可能是輸入錯誤或真實罕見事件
→ IQR法 / Z分數 / 孤立森林
重複值
Duplicates
同一觀察多次出現；高估頻次、影響模型
→ 唯一識別碼偵測並移除
一致性錯誤
Inconsistency
單位/格式不統一；「臺北市」vs「台北市」
→ 標準化命名規則格式
邏輯錯誤
Logical Errors
格式正確但違反邏輯（出生年1890、負金額、體溫43°C）→ 設定規則範圍 (年齡0-120)
資料品質評估指標
缺失率
各欄位空值/缺漏資料的比例；高缺失率影響特徵可用性
唯一值比率
主鍵出現重複 → 嚴重破壞資料正確性
一致性比率
欄位格式、單位、命名標準是否統一
異常值比率
明顯偏離正態分佈或超出上下限的資料比例
完整性比率
觀察對象是否具備足夠的資料描述 (多欄位完整性)
4.2 數據儲存與管理
資料型態與儲存技術
結構化
Structured
RDBMS：MySQL / PostgreSQL / Oracle
固定欄位、SQL查詢、ACID特性、ERP/CRM/POS來源
⚠ 結構固定，模式變動靈活度低
半結構化
Semi
NoSQL：MongoDB / ElasticSearch / 資料湖
JSON / XML / YAML；API傳輸、IoT封包、網站內容
⚠ 缺乏結構約束，查詢邏輯需自定
非結構化
Unstructured
物件儲存：S3 / MinIO / HDFS
文字、圖片、音訊、影片；需 metadata 管理系統
⚠ 難以直接搜尋，需外部標註與索引
分散式儲存 & 資料湖架構
分散式特性：橫向擴充 · 容錯容災 · 高並行存取 · 資料本地性
Lakehouse：ACID操作 + 版本控制 + 即時查詢 (Delta Lake / Apache Iceberg / Hudi)
ACID 交易特性
A
Atomicity 原子性
全做完 或 全不做，無法只執行部分
C
Consistency 一致性
交易前後維持邏輯一致狀態（主鍵/外鍵約束）
I
Isolation 隔離性
並行交易互不干擾，如同獨立執行
D
Durability 持久性
Commit 後永久保存，系統當機不遺失
資料一致性策略
強一致性
寫入後所有讀取即時得最新狀態
適用：金融交易、帳務
技術：Delta Lake, Iceberg
最終一致性
允許短時間非同步，最終趨一致
適用：S3、HDFS 物件儲存
高吞吐，犧牲即時性
存取控制模型 Access Control
RBAC
角色存取控制
依角色（工程師/分析師/主管）控管；邏輯清楚、中小企業常用
ABAC
屬性存取控制
依使用者屬性+資料屬性+環境條件；彈性高，大型企業
PBAC
策略存取控制
預設策略規則 (OPA/Rego)；雲端平台、跨系統整合
DAC
自主存取控制
資料擁有者自決誰可存取；彈性高，研發小團隊
Zero Trust：不信任任何人，持續驗證 · 最小權限 · 動態授權 (JIT)
4.3 數據處理技術與工具
清理後的資料準備轉換
清理完 → 型態轉換 → 標準化 → 編碼 → 可分析狀態
類別變數編碼方式 Encoding
Label Encoding 標籤編碼
每類別 → 整數（小學→0, 高中→1, 大學→2）
✓ 有序類別 (Ordinal)；⚠ 誤用於無序類別會誤導模型
One-hot Encoding 獨熱編碼
每類別 → 獨立二元欄位（紅/藍/綠 → 3欄位）
✓ 無序類別 (Nominal)；⚠ 高基數導致維度爆炸
Target Encoding 目標編碼
以目標變數統計量（平均轉換率）取代類別值
✓ 高基數類別且與目標高度關聯；⚠ 需防資料洩漏
數值標準化 / 正規化
方法 公式 / 範圍 注意
Min-Max
最小最大正規化		 [0, 1]
(x-min)/(max-min)		 ⚠ 對極端值敏感
Z-score
標準化		 μ=0, σ=1
(x-μ)/σ		 ⚠ 資料偏態時偏移
Robust
穩健標準化		 中位數 + IQR
(x-median)/IQR		 ✓ 偏態/離群值強健
何時需要縮放？ KNN、梯度下降、神經網路、正則化模型 (Lasso/Ridge) 必要前處理；決策樹類模型不受影響
特徵工程 Feature Engineering
特徵選擇 Feature Selection
Filter
過濾法
統計量篩選 (Pearson/χ²/ANOVA)
速度快，不依賴模型；缺：無法考量特徵交互
Wrapper
包裝法
RFE / 前向後向選擇
模型表現為標準，精確考量交互；計算成本高
Embedded
嵌入法
Lasso / Ridge / 決策樹重要性
訓練同時完成特徵選擇；需特定模型支援
特徵衍生 Feature Generation
交互特徵 (乘積/除法) 時間特徵 (星期/假日/Recency) 聚合特徵 (群組統計) 分箱 Binning (等寬/等頻/K-Means)
資料增強 Data Augmentation
🖼️
圖像增強
翻轉、旋轉、裁剪、色彩變換；人臉辨識、醫學影像
📝
文字增強
同義詞替換、隨機插入/刪除；情感分析、對話模型
📈
時序增強

⚠ 注意：避免資料洩漏 (Data Leakage)；增強需在 cross-validation 或 time-window 外進行
儲存效能優化策略
分區儲存 Partitioning — 依時間/地區分區，縮小查詢掃描範圍
壓縮技術 — Parquet/ORC + Snappy/ZSTD，降低I/O成本
儲存分層 Tiering — 熱資料→SSD；冷資料→HDD/雲端
欄位裁剪 Column Pruning — 查詢時僅讀必要欄位，減少I/O
物化檢視 Materialized View — 預計算重複查詢 (BI報表加速)
