科目三・第三章

第三章名詞解釋：機器學習基礎數學

機率與統計・線性代數・數值優化 ── 共 30 個核心名詞

Random Variable
隨機變數
將隨機實驗的結果對應到實數的函數，X: Ω → ℝ。分為離散型（可數結果）與連續型（不可數結果）兩類。
🎲 情境分析擲骰子點數 X∈{1,…,6} 是離散型；量測某人身高 H 是連續型隨機變數。
📝 考題方向區分離散/連續型的判斷，及後續 PMF/PDF 的適用條件。
Probability Mass Function
機率質量函數
PMF
描述離散型隨機變數取各值的機率，P(X=x)≥0，且 ΣP(X=x)=1。每根柱子代表某個具體值的機率。
🎲 情境分析擲公平骰子，P(X=1)=P(X=2)=…=P(X=6)=1/6，各點機率相等。
📝 考題方向PMF 對應離散型；PDF 對應連續型；兩者積分或加總皆為 1。
Probability Density Function
機率密度函數
PDF
描述連續型隨機變數的機率分佈，f(x)≥0，區間積分 ∫f(x)dx=1。P(a≤X≤b) 等於曲線下面積。
📊 情境分析身高服從常態分佈，160~170cm 之間的機率 = 常態 PDF 在此區間的積分面積。
📝 考題方向PDF 本身不是機率（可能>1）；積分才是機率，單點機率 P(X=x)=0。
Bernoulli Distribution
伯努利分佈
最簡單的離散分佈，只有兩種結果：成功(X=1,機率p)或失敗(X=0,機率1−p)。E[X]=p, Var[X]=p(1−p)。
📧 情境分析判斷一封信是否為垃圾郵件，每封信獨立地服從 Bernoulli(p) 分佈。
📝 考題方向邏輯迴歸輸出的機率即為 Bernoulli 分佈的參數 p；二項分佈是 n 次 Bernoulli 的加總。
Binomial Distribution
二項分佈
n 次獨立 Bernoulli 試驗中，成功 k 次的機率：P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。E[X]=np, Var[X]=np(1−p)。
📦 情境分析100 件產品各自 5% 不良率，抽 10 件中有 k 件不良的機率服從 B(10, 0.05)。
📝 考題方向n→∞ 時趨近常態分佈（中央極限定理）；n 大 p 小時趨近 Poisson 分佈。
Poisson Distribution
泊松分佈
描述單位時間/空間內，稀有事件發生次數的分佈。P(X=k)=λᵏe⁻λ/k!，其中 λ>0 為平均發生率，且 E[X]=Var[X]=λ。
☎️ 情境分析客服中心每小時平均接到 5 通電話，X=某小時接到電話次數 ~ Poisson(5)。
📝 考題方向E[X]=Var[X]=λ 是 Poisson 特性；考題常問「稀有事件、單位時間」等關鍵詞對應此分佈。
Normal / Gaussian Distribution
常態分佈
最重要的連續機率分佈，N(μ,σ²)，由均值μ和變異數σ²決定。具有對稱鐘形曲線，68-95-99.7 法則：±σ含68%，±2σ含95%，±3σ含99.7%數據。
📏 情境分析人類身高、測量誤差、股票日報酬率通常近似常態分佈，中央極限定理保證其廣泛性。
📝 考題方向標準化 Z=(X−μ)/σ；MLE 在常態假設下對應 MSE 損失函數；考題常考 68/95/99.7 數值。
Uniform Distribution
均勻分佈
在 [a,b] 區間內每點機率相等，f(x)=1/(b−a)，E[X]=(a+b)/2，Var[X]=(b−a)²/12。離散版：各結果等機率。
🔧 情境分析神經網路權重隨機初始化（Xavier 初始化）時，常使用均勻分佈 U(−√6/n, √6/n)。
📝 考題方向常作為先驗分佈（無資訊先驗）；權重初始化與隨機種子的基礎分佈。
Exponential Distribution
指數分佈
描述等待時間的連續分佈，f(t)=λe⁻λt，E[T]=1/λ。具有無記憶性：P(T>s+t|T>s)=P(T>t)。
⏱️ 情境分析網路封包到達間隔時間、設備故障間隔時間常用指數分佈建模，λ 為事件發生率。
📝 考題方向無記憶性是指數分佈的唯一特性；Poisson 過程中事件間隔時間服從指數分佈。
Chi-square Distribution
卡方分佈
χ²
k 個獨立標準常態隨機變數平方和的分佈：χ²(k)=Z₁²+…+Zk²。E[χ²]=k，常用於獨立性檢定與配適度檢定。
🗃️ 情境分析用於檢定類別型特徵是否獨立（如性別與購買偏好），或模型預測分佈是否符合預期。
📝 考題方向卡方檢定是非參數檢定；自由度 k 影響分佈形狀；p 值小於 α 表示拒絕獨立假設。
Conditional Probability
條件機率
在 B 已發生的條件下，A 發生的機率：P(A|B)=P(A∩B)/P(B)（P(B)>0）。條件機率縮小了樣本空間。
🔍 情境分析已知用戶是 VIP 會員 (B)，求其購買高端商品 (A) 的機率，即 P(A|B)。
📝 考題方向條件機率是貝氏定理的基礎；獨立性定義為 P(A|B)=P(A)，即 B 不影響 A 的機率。
Bayes' Theorem
貝氏定理
P(θ|X) = P(X|θ)·P(θ) / P(X)，即後驗 ∝ 似然 × 先驗。在觀測到數據 X 後，更新對參數 θ 的信念。
📧 情境分析垃圾郵件過濾：先驗=垃圾郵件比例，似然=該郵件包含某詞的機率，後驗=是垃圾的機率。
📝 考題方向MLE 只用似然；MAP 加入先驗（等同 L2 正則化）；貝氏推斷給出完整後驗分佈。
Prior / Posterior Probability
先驗/後驗機率
先驗 P(θ)：觀測數據前對參數的信念（主觀或歷史數據）。後驗 P(θ|X)：觀測數據後更新的信念，通常比先驗更集中（不確定性降低）。
🩺 情境分析疾病篩檢：先驗=人群患病率1%，檢測陽性後更新→後驗大幅提高至50%（取決於偽陽率）。
📝 考題方向先驗為均勻分佈時 MAP≡MLE；Conjugate Prior（共軛先驗）可讓後驗與先驗同族。
Maximum Likelihood Estimation
最大似然估計
MLE
找到使觀測數據 X 出現機率最大的參數估計：θ̂=argmax∑logP(xᵢ|θ)。對數似然使乘積變加法，數值更穩定。
📈 情境分析線性迴歸在常態誤差假設下，MLE 等價於最小化 MSE（因 logL ∝ −MSE）。
📝 考題方向MLE 無先驗；考題常問MLE與MSE/Cross-Entropy的等價關係，及加入先驗後的 MAP 差異。
Hypothesis Testing
假設檢定
對一個統計假設（H₀ 虛無假設 vs H₁ 對立假設）進行決策的程序。計算檢定統計量，若落入拒絕域（p值＜α），則拒絕 H₀。
🧪 情境分析A/B 測試：H₀：新版本與舊版本轉換率無差異。計算 z 值，p<0.05 則推翻 H₀，採用新版本。
📝 考題方向Type I 錯誤(α)：誤拒真 H₀；Type II 錯誤(β)：漏拒假 H₀；Power=1−β。
p-value & Significance Level α
p值與顯著水準
p值：在 H₀ 成立下，觀測到現有或更極端結果的機率。顯著水準 α：通常設 0.05 或 0.01，為 Type I 錯誤的容忍上限。p＜α → 拒絕 H₀。
🔬 情境分析模型 A vs B 的準確率差異：p=0.03 < α=0.05，統計上顯著，認為差異非隨機。
📝 考題方向p值不是「效果大小」；p值大不等於 H₀ 為真；只表示沒有足夠證據拒絕 H₀。
Vector
向量
有方向和大小的量，可以表示特徵空間中的一個點（數據樣本）或一個方向（梯度）。在 ML 中，每個樣本通常表示為一個 d 維特徵向量。
📦 情境分析一封郵件的 TF-IDF 特徵向量（每個詞的重要性）是高維向量，用於文字分類模型。
📝 考題方向向量的 L2 範數（長度）、向量夾角（餘弦相似度）常考；梯度本身是損失函數的梯度向量。
Matrix
矩陣
m×n 個數值排列成的二維陣列。在 ML 中，n 個樣本×d 個特徵的數據集表示為 n×d 矩陣 X；權重矩陣 W 定義神經網路層的線性變換。
🧠 情境分析神經網路的前向傳播 z = Wx + b，W 是權重矩陣，每次矩陣乘法完成一次線性變換。
📝 考題方向OLS 解析解 β=(XᵀX)⁻¹Xᵀy；矩陣可逆條件（行列式≠0）；轉置與共軛轉置的差異。
Dot Product (Inner Product)
點積
兩個等長向量逐元素相乘再加總：a·b=∑aᵢbᵢ。幾何意義：|a||b|cosθ，衡量兩向量方向相似程度，是神經網路線性層與注意力機制的核心運算。
🤖 情境分析Transformer 的縮放點積注意力：score = (QKᵀ)/√d，Q 和 K 的點積衡量查詢與鍵的相關性。
📝 考題方向a·b=0 ⟺ 正交；餘弦相似度用於文字向量比較；點積是矩陣乘法的構件。
Eigenvalue Decomposition
特徵值分解
對方形矩陣 A，找到滿足 Av=λv 的特徵向量 v 和特徵值 λ。分解形式 A=QΛQᵀ，特徵值大小代表對應方向的「重要性」，PCA 的核心計算。
📊 情境分析PCA 計算共變異矩陣的特徵值分解，選取最大特徵值對應的特徵向量作為主成分方向。
📝 考題方向僅適用於方形矩陣；SVD 是更一般化的版本，適用任意矩陣；考題辨別 PCA 用哪種分解。
Singular Value Decomposition
奇異值分解
SVD
將任意 m×n 矩陣分解：X=UΣVᵀ，U/V 為正交矩陣，Σ 為奇異值對角矩陣（σ₁≥σ₂≥…≥0）。截斷前 k 個奇異值可做低秩近似，用於降維、推薦系統。
🎬 情境分析Netflix 推薦系統：將用戶-電影評分矩陣做截斷 SVD，填補缺失值並找潛在因子。
📝 考題方向SVD 適用任意矩陣（PCA 需方陣）；截斷 SVD 等於矩陣的最佳低秩近似（Eckart-Young 定理）。
Principal Component Analysis
主成分分析
PCA
找到最大方差方向的正交投影，將高維數據降至低維，同時保留最多信息。計算共變異矩陣的特徵向量，按特徵值大小排序，選前 k 個主成分。
🖼️ 情境分析人臉辨識：256×256 像素圖片（65536 維）→ PCA 降至 200 維特征臉（Eigenface），大幅減少計算。
📝 考題方向PCA 是無監督；LDA 是監督式；考解釋方差比（explained variance ratio）決定保留幾個主成分。
Linear Discriminant Analysis
線性判別分析
LDA
監督式降維方法，找到最大化類別間分散、最小化類別內分散的投影方向。與 PCA 不同：LDA 利用標籤信息，目標是區分類別而非保留整體方差。
🔬 情境分析醫學診斷：將患者多個生理指標投影到 LDA 方向，使健康/患病群體分離最大化，提升分類準確率。
📝 考題方向PCA（無監督，最大方差）vs LDA（監督，最大類別分離）；LDA 假設類別內協方差相同。
Loss Function
損失函數
衡量模型預測值與真實值差距的函數，訓練目標是最小化損失。常見：MSE（回歸）、Cross-Entropy（分類）、Huber Loss（抗離群值）、Focal Loss（類別不平衡）。
🎯 情境分析詐騙偵測：正負樣本嚴重不平衡，使用 Focal Loss 對難分樣本（詐騙案例）加大損失權重。
📝 考題方向MSE 對離群值敏感；MAE 對離群值穩健；Cross-Entropy = MLE 下的負對數似然；考題常問選擇依據。
Gradient Descent
梯度下降
GD
用全部訓練數據計算梯度，更新參數：θ ← θ − η∇L(θ)。η 為學習率。優點：梯度準確；缺點：大數據集每步計算昂貴，更新慢。
⚙️ 情境分析小型數據集（數千樣本）訓練線性迴歸時，每次更新使用全部樣本，收斂穩定。
📝 考題方向GD vs SGD vs Mini-batch：批次大小影響梯度噪聲、記憶體用量、收斂速度的三向取捨。
Stochastic Gradient Descent
隨機梯度下降
SGD
每次只用1個樣本估計梯度並更新參數。更新頻繁、速度快，但梯度噪聲大，損失震盪。優點：可跳脫局部極小值；缺點：收斂路徑不穩定。
🌊 情境分析大型語言模型在線學習（Online Learning）場景：每到一筆新數據立即更新模型參數。
📝 考題方向SGD 的噪聲有助逃脫局部最優；但噪聲過大時需加學習率衰減或改用 Mini-batch。
Mini-batch Gradient Descent
小批量梯度下降
Mini-batch
每次用 B 個樣本（B 通常 32~512）估計梯度更新。兼顧 GD（梯度準確）與 SGD（更新頻繁）的優點，也能充分利用 GPU 平行運算，是深度學習的標準訓練方式。
🖥️ 情境分析ImageNet 訓練 ResNet-50：batch size=256，每次讀入 256 張圖計算梯度，更新一次權重。
📝 考題方向Batch size 越大梯度越穩定但記憶體需求越高；太小則噪聲大；通常為 2 的次方以利 GPU 優化。
Adam Optimizer
Adam 優化器
Adam

(mₜ) RMSprop
(vₜ) + Adam m̂ₜ/(√v̂ₜ+ε)
結合動量（Momentum）的一階矩估計與RMSprop的二階矩估計：θ ← θ − α·m̂ₜ/(√v̂ₜ+ε)。自適應學習率，β₁=0.9, β₂=0.999。深度學習最廣泛使用的優化器。
🚀 情境分析Transformer 模型訓練：Adam 自動調整各參數的學習率，注意力層的稀疏梯度也能有效更新。
📝 考題方向Adam = Momentum + RMSprop 的偏差修正版；考題問 β₁(一階矩)/β₂(二階矩)/ε(防零除)的作用。
Learning Rate Schedule
學習率調整
隨訓練進行動態調整學習率的策略。常見方法：Step Decay（定期衰減）、Cosine Annealing（餘弦衰減）、Warmup（先升後降，Transformer 常用）、Cyclical LR（周期性波動）。
🌡️ 情境分析BERT 預訓練使用線性 Warmup（前 10% 步數升至最大學習率）再線性衰減，穩定大模型訓練初期。
📝 考題方向學習率太大：震盪發散；太小：收斂慢；Warmup 解決訓練初期不穩定；Cosine 比 Step 更平滑。
Gradient Clipping
梯度裁剪
當梯度範數超過閾值 θ_max 時，等比縮放梯度：g ← g·θ_max/‖g‖。防止訓練 RNN/LSTM 時的梯度爆炸問題（梯度通過時間反向傳播而指數增長）。
📝 情境分析訓練 LSTM 語言模型時，梯度突然爆炸至 1e5，設置 clip_grad_norm=5 後訓練穩定收斂。
📝 考題方向梯度裁剪解決「梯度爆炸」；梯度消失用 LSTM/殘差連接/BatchNorm 解決，兩者對應不同問題。
