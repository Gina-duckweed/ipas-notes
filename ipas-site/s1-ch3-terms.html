3.1 自然語言處理
Tokenization
斷詞 / 分詞
將連續文字切割為最小意義單元（Token），可為字、詞或子詞（Subword）。BPE（Byte-Pair Encoding）是常見子詞切割演算法。
🔍 應用場景NLP 前處理第一步，適用中英文所有語言模型輸入。
⚡ 考試提示Subword Tokenization（如 BPE）可平衡詞彙量與未知詞問題。
Named Entity Recognition
命名實體識別
NER
從文本中自動識別並分類具有特定意義的實體，如人名、地名、組織機構名稱、時間、金額等。
🔍 應用場景新聞資訊擷取、法律文件分析、醫療病歷結構化。
⚡ 考試提示NER 屬於序列標注任務，常用 CRF 或 Transformer 模型處理。
Word Embeddings
詞向量 / 詞嵌入
將詞彙映射為低維稠密向量，使語義相似的詞在向量空間中距離相近。代表方法：Word2Vec、GloVe、FastText。
🔍 應用場景NLP 特徵表示基礎，用於文字分類、情感分析、推薦系統。
⚡ 考試提示Word2Vec 有 CBOW 和 Skip-gram 兩種訓練方式；FastText 支援子詞。
TF-IDF
詞頻-逆文件頻率
統計加權方法，衡量詞彙在特定文件中的重要性。TF（詞頻）高且 IDF（逆文件頻率）高，表示該詞對該文件有辨識力。
🔍 應用場景資訊檢索、文件分類、關鍵詞提取。
⚡ 考試提示停用詞（如「的」「是」）IDF 低，TF-IDF 分數低，自動降權。
Transformer
轉換器架構
以 Self-Attention 機制為核心的深度學習架構，能並行計算序列中各位置的依賴關係，打破 RNN 的順序限制，成為現代 NLP 基礎。
🔍 應用場景BERT、GPT、T5 等所有主流語言模型的底層架構。
⚡ 考試提示「Attention is All You Need」（2017 Google）提出；Encoder-only / Decoder-only / Encoder-Decoder 三種變體。
BERT
雙向編碼表示
Google 提出的雙向 Transformer 編碼器，透過 Masked Language Model（MLM）與 Next Sentence Prediction（NSP）預訓練，同時理解上下文。
🔍 應用場景文本分類、問答系統、語義相似度比對。
⚡ 考試提示BERT 雙向理解，適合分類任務；GPT 單向生成，適合文本生成任務。
Sentiment Analysis
情感分析
自動辨識文本中表達的情緒傾向（正面/負面/中性），可進一步細分為多類別情感或情緒強度評估。
🔍 應用場景品牌監控、顧客回饋分析、社群媒體輿情偵測。
⚡ 考試提示屬監督式分類任務，訓練資料需標注情感標籤；零樣本可用 LLM 完成。
Machine Translation
機器翻譯
自動將一種自然語言翻譯成另一種語言。現代主流為基於 Transformer 的 Seq2Seq 模型（Encoder-Decoder 架構），如 NLLB、mBART。
🔍 應用場景跨語言文件處理、即時翻譯服務、多語系客服。
⚡ 考試提示BLEU 分數（Bilingual Evaluation Understudy）為機器翻譯主要評估指標。
Text Summarization
文本摘要生成
自動從長篇文本中提取或生成精簡摘要。抽取式（Extractive）：直接選取原句；生成式（Abstractive）：重新組句生成，需生成模型。
🔍 應用場景新聞摘要、法律文件精華、會議紀錄自動化。
⚡ 考試提示抽取式用相似度排序；生成式用 T5/BART/GPT 等 Seq2Seq 模型。
Attention Mechanism
注意力機制
讓模型在處理序列時，動態計算輸入各位置的相關性權重。Self-Attention 計算每個 token 與其餘所有 token 的相似度，Multi-Head Attention 並行執行多組注意力、捕捉不同維度語義。Scaled Dot-Product Attention 公式：softmax(QKᵀ/√d)V。
🔍 應用場景BERT、GPT 等所有 Transformer 模型的核心；機器翻譯對齊來源與目標詞彙；摘要模型關注關鍵句。
⚡ 考試提示Q/K/V（Query/Key/Value）三要素必記；Self-Attention 複雜度 O(n²)，長序列計算量大；Cross-Attention 用於 Encoder→Decoder 資訊橋接。
LSTM / RNN
長短期記憶 / 遞迴神經網路
LSTM
RNN（Recurrent Neural Network）透過隱藏狀態傳遞序列資訊，但面臨梯度消失問題。LSTM 引入輸入門、遺忘門、輸出門三個門控機制，可選擇性記憶或遺忘，有效捕捉長程依賴。GRU 是 LSTM 的簡化版。
🔍 應用場景時序預測（股價、氣象）、語音辨識、文本生成；Transformer 普及前 NLP 主流架構。
⚡ 考試提示LSTM 解決 RNN 梯度消失問題；Transformer 取代 RNN 成為 NLP 主流後，LSTM 仍用於資源受限場景；三門（Input Gate、Forget Gate、Output Gate）考試常考。
3.2 電腦視覺
Convolutional Neural Network
卷積神經網路
CNN
專為影像設計的深度神經網路，透過卷積核自動學習局部空間特徵，具平移不變性。由卷積層、池化層、全連接層組成。
🔍 應用場景影像分類、物件偵測、人臉辨識、醫療影像分析。
⚡ 考試提示池化（Max Pooling）降低特徵圖尺寸，減少參數量；代表模型：ResNet（殘差連接解決梯度消失）。
Transfer Learning
遷移學習
將在大型資料集（如 ImageNet）預訓練的模型權重應用於新任務，透過 Fine-tuning 微調部分層，大幅降低訓練資料與算力需求。
🔍 應用場景醫療影像診斷（小量標注資料）、工廠瑕疵偵測。
⚡ 考試提示常見策略：凍結底層特徵層，只訓練頂層分類器（Feature Extraction）或全層微調（Full Fine-tuning）。
Object Detection
物件偵測
在影像中同時定位並分類多個物件，輸出邊界框（Bounding Box）與類別標籤。主要分兩階段（Faster R-CNN）和單階段（YOLO）兩類框架。
🔍 應用場景自動駕駛感知、工業產線檢測、人流監控、零售貨架管理。
⚡ 考試提示YOLO 速度快（即時）；Faster R-CNN 精度高但較慢；mAP 為偵測評估指標。
Semantic Segmentation
語義分割
對影像中每個像素進行類別預測，將整張影像劃分為語義區域（如道路、天空、行人）。比物件偵測更細緻，但計算成本更高。
🔍 應用場景自動駕駛場景理解、衛星影像分析、醫療組織分割。
⚡ 考試提示代表模型：U-Net（醫療）、DeepLab（場景）；評估指標：mIoU（平均交並比）。
Image Classification
影像分類
對整張影像分配一個或多個類別標籤，是電腦視覺最基礎任務。代表模型包括 ResNet、VGG、EfficientNet、ViT（Vision Transformer）。
🔍 應用場景產品缺陷分類、植物病害辨識、X光胸部疾病篩查。
⚡ 考試提示ResNet 引入殘差連接（Skip Connection）解決深度網路梯度消失問題。
YOLO
即時物件偵測框架
You Only Look Once，單階段物件偵測框架，將偵測問題轉為迴歸任務，一次前向傳播同時預測多個邊界框與類別，速度遠快於兩階段方法。
🔍 應用場景即時監控攝影機、邊緣裝置部署、車牌辨識、交通流量分析。
⚡ 考試提示YOLO 速度優先；Faster R-CNN 精度優先；考題常考兩者取捨。
3.3 生成式 AI
Large Language Model
大型語言模型
LLM
基於 Transformer 的超大規模語言模型，以海量文本預訓練，具備語言理解、生成、推理等通用能力。代表：GPT-4、LLaMA、Claude、Gemini。
🔍 應用場景智慧客服、程式碼生成、文案撰寫、知識問答、多步驟推理。
⚡ 考試提示核心問題：幻覺（Hallucination）— 生成看似合理但不實的內容，需 RAG 或 Grounding 技術緩解。
Prompt Engineering
提示詞工程
設計與優化輸入提示以引導 LLM 輸出預期回應的技術。包括 Zero-shot、Few-shot、Chain-of-Thought、Role Prompting 等策略。
🔍 應用場景提升 LLM 任務表現、減少幻覺、引導複雜推理流程。
⚡ 考試提示Chain-of-Thought（CoT）引導模型「分步推理」，顯著提升數學與邏輯任務準確率。
Retrieval-Augmented Generation
檢索增強生成
RAG
結合外部知識庫與 LLM 生成能力：先從向量資料庫檢索相關文件片段，再輸入 LLM 生成基於事實的回答，降低幻覺並提升知識時效性。
🔍 應用場景企業知識庫問答、法規查詢、客服機器人知識更新。
⚡ 考試提示RAG = 向量搜尋（Embedding Similarity）+ LLM 生成；不需重新訓練模型即可更新知識。
Fine-tuning / LoRA
微調 / 低秩適應
Fine-tuning：在預訓練模型基礎上，用特定領域資料繼續訓練部分或全部權重。LoRA（Low-Rank Adaptation）：在原始權重矩陣旁插入低秩矩陣，大幅減少可訓練參數量。
🔍 應用場景法律/醫療領域模型客製化、公司內部資料微調。
⚡ 考試提示LoRA 只更新少量參數（原模型凍結），顯著降低 GPU 記憶體需求。
Reinforcement Learning from Human Feedback
人類反饋強化學習
RLHF
透過收集人類對模型輸出的偏好評分，訓練獎勵模型（Reward Model），再用強化學習（PPO）調整 LLM 輸出，使其更安全、有用、符合人類偏好。
🔍 應用場景ChatGPT、Claude 等對話模型對齊訓練，減少有害輸出。
⚡ 考試提示RLHF 三步驟：SFT（監督微調）→ 訓練Reward Model → PPO 強化學習優化。
Hallucination
幻覺（AI幻覺）
LLM 生成看似合理但實際錯誤或虛構的內容，如捏造文獻、錯誤事實、不存在的 API。根本原因是模型依賴統計模式而非真實世界知識。
🔍 應用場景所有 LLM 應用場景均需防範；高風險場景（醫療/法律）需人工審查。
⚡ 考試提示緩解幻覺的方法：RAG（外部知識接地）、Grounding、事實驗證後處理。
In-context Learning
情境學習
ICL
LLM 在 Prompt 中提供少量範例即可執行新任務、無需更新模型參數的能力。Zero-shot：無範例直接推論；One-shot：提供一個範例；Few-shot：提供多個範例，模型從情境推斷任務規則，是 GPT 系列的核心能力之一。
🔍 應用場景企業使用 Few-shot Prompt 讓 LLM 遵循特定輸出格式；快速適應情感分析、程式轉換、分類等新任務，無需重新訓練。
⚡ 考試提示ICL vs Fine-tuning：ICL 不改變模型權重（成本低、彈性高）；Fine-tuning 調整參數（特定領域表現更穩定）。Zero/One/Few-shot 的區分是考試高頻考點。
3.4 多模態 AI 與生成模型
Generative Adversarial Network
生成對抗網路
GAN
包含生成器（Generator）與判別器（Discriminator）兩個網路的對抗訓練框架。生成器學習產生逼真樣本，判別器判斷真偽，雙方博弈達到納什均衡。
🔍 應用場景人臉合成、影像風格轉換、資料增強、Deepfake 偵測。
⚡ 考試提示主要缺點：訓練不穩定、模式崩潰（Mode Collapse，生成器只產出少數類型樣本）。
Variational Autoencoder
變分自編碼器
VAE
學習輸入資料的潛在空間機率分佈（均值μ與方差σ），透過重參數化技巧進行可微分採樣，在潛在空間插值可生成平滑多樣的新樣本。
🔍 應用場景異常偵測、藥物分子生成、語音重建、隱變數建模。
⚡ 考試提示VAE 生成樣本平滑但細節稍模糊；GAN 細節清晰但訓練不穩定。
Diffusion Model
擴散生成模型
透過逐步向資料加入高斯噪聲（前向擴散），再學習逐步去噪（反向擴散）以生成新樣本的生成模型。Stable Diffusion、DALL-E 2 為代表作。
🔍 應用場景文字生成圖像（Text-to-Image）、影像修復、超解析度重建。
⚡ 考試提示生成品質三者對比：Diffusion > GAN（穩定性） > VAE（清晰度）；Diffusion 速度最慢。
CLIP
圖文對比學習模型
OpenAI 提出的對比學習模型，同時訓練圖像編碼器與文字編碼器，使匹配的圖文對在向量空間靠近，不匹配的遠離。支援零樣本圖像分類。
🔍 應用場景跨模態搜索（以文找圖）、零樣本分類、DALL-E / Stable Diffusion 的引導組件。
⚡ 考試提示CLIP 無需針對特定類別訓練，直接以文字描述作為分類標準（Zero-shot）。
Visual Question Answering
視覺問答
VQA
模型同時接收影像與自然語言問題，輸出基於圖像內容的回答。融合視覺特徵提取（CNN/ViT）與語言理解（BERT/GPT）兩大能力。
🔍 應用場景醫療影像問診、智慧教育圖文理解、無障礙輔助（描述圖像內容）。
⚡ 考試提示VQA 是多模態 AI 的核心評測基準；GPT-4V、Gemini Vision 已具備強大 VQA 能力。
Multimodal Large Language Model
多模態大語言模型
MLLM
能同時處理多種模態輸入（文字、圖像、音訊、影片）的大型模型。代表：GPT-4V、Gemini、Claude 3 Sonnet，整合視覺編碼器與語言模型。
🔍 應用場景圖文理解、影像描述生成、文件OCR、跨模態推理。
⚡ 考試提示多模態 = 視覺 Encoder（如 ViT）+ 語言 Decoder（LLM），透過 Cross-Attention 或 Projection Layer 橋接。
