程式碼逐步說明 Step-by-Step

1

載入資料集與探索性分析（EDA）

150 筆 × 4 特徵 × 3 類別 
from sklearn.datasets import load_iris
import pandas as pd

iris = load_iris()
X, y = iris.data, iris.target

# 轉為 DataFrame 方便觀察
df = pd.DataFrame(X, columns=iris.feature_names)
df['species'] = pd.Categorical.from_codes(y, iris.target_names)

print(df.groupby('species').agg(['mean','std']).round(2))
# 資料集：150 筆，3 類各 50 筆（完全平衡）
# 4 特徵：sepal length/width, petal length/width（單位：cm）
重點：Iris 資料集完全平衡（每類 50 筆），無缺失值，是分類演算法教學的標準基準。Setosa 在花瓣尺寸上與另外兩類差異極大，是線性可分的；Versicolor 與 Virginica 有部分重疊。
2

資料分割與標準化

train 105 / test 45（7:3） 
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3,       # 30% 測試集
    stratify=y,          # 分層取樣：保持各類比例一致
    random_state=42
)

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)  # fit + transform（訓練集）
X_test_s  = scaler.transform(X_test)       # 只 transform（測試集，防止 Data Leakage）
重點：stratify=y 確保分割後各類比例一致（各 35/15 筆）。StandardScaler 必須只在訓練集 fit，再 transform 測試集，否則測試集資訊會「洩漏」進訓練流程（Data Leakage）。
3

建立羅吉斯迴歸模型

OvR 多分類策略 
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    max_iter=300,     # 最大迭代次數（預設 100 可能不收斂）
    random_state=42   # 重現性
)
# sklearn 預設使用 OvR（One-vs-Rest）多分類策略
# 對每個類別訓練一個「是/否」二元分類器，共 3 個

model.fit(X_train_s, y_train)

# 羅吉斯迴歸的核心公式：
# P(y=k|x) = σ(wₖᵀx + bₖ)  其中 σ 為 Sigmoid 函數
# 多分類 → Softmax：P(y=k|x) = exp(wₖᵀx) / Σ exp(wⱼᵀx)
重點：羅吉斯迴歸輸出的是機率值（0~1），透過 Sigmoid/Softmax 函數將線性組合 Wᵀx+b 壓縮至機率空間。OvR 對每個類別各訓練一個二元分類器，預測時選機率最高的類別。
4

評估模型效能

混淆矩陣 · 分類報告 · 交叉驗證 
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.model_selection import cross_val_score, StratifiedKFold

y_pred = model.predict(X_test_s)
y_prob = model.predict_proba(X_test_s)  # 各類別機率

print(classification_report(y_test, y_pred, target_names=iris.target_names))
print(confusion_matrix(y_test, y_pred))

# 5-Fold 交叉驗證（更可靠的效能估計）
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = cross_val_score(model, scaler.transform(X), y, cv=cv)
print(f"CV Accuracy: {cv_scores.mean():.4f} ± {cv_scores.std():.4f}")
# → 0.9533 ± 0.0452
重點：單次 train/test split 結果受隨機分割影響。5-Fold Stratified CV 把資料分成 5 份輪流當測試集，平均後得更穩定估計（95.33%）。predict_proba() 回傳各類別的機率向量，用於計算 AUC-ROC。

結果分析與洞察 Insights

🎯 模型準確性
  • Setosa 完美分類（F1=1.00）：花瓣尺寸與另外兩類差距顯著，線性邊界即可完全分離，屬線性可分（Linearly Separable）。
  • Versicolor vs Virginica 混淆：3 筆 virginica 被誤判為 versicolor，兩類在特徵空間有重疊，是 Iris 資料集的固有難點。
  • 5-Fold CV 95.33%：比單次 test 91.11% 更可靠，說明模型在不同資料切割下表現穩定，無過擬合問題。
📐 係數解讀（Coefficients）
  • Petal length/width 係數最大：對分類貢獻最高，花瓣尺寸是判斷品種的主要特徵；sepal 特徵影響相對較小。
  • Virginica：petal width 係數 +2.396，petal length +1.816，代表花瓣越大越傾向 virginica。
  • Setosa：petal length 係數 −1.70、petal width −1.60，即花瓣小 → setosa 機率高，符合直覺。
⚡ 羅吉斯迴歸的優缺點
  • 優點：輸出機率（可解釋性強）；訓練速度快；係數直接反映特徵重要性；不容易過擬合（有 L2 正則化）。
  • 限制：只能學習線性決策邊界；特徵需要標準化；對高度非線性問題效果不佳（需 kernel 方法或深度學習）。
  • 適用場景：信用評分 Scorecard、醫療診斷輔助、二元/多元分類基線模型。
🔑 考試重點整理
  • Sigmoid vs Softmax：二元分類用 Sigmoid，多分類用 Softmax（OvR 是用多個 Sigmoid）。
  • 損失函數：Binary Cross-Entropy（Log Loss）：−[y log(p) + (1−y) log(1−p)]。
  • 正則化：L1（Lasso，稀疏解）vs L2（Ridge，縮小係數，預設）；C 參數越小正則化越強。
  • AUC=1.0（setosa）：代表在任何閾值下都能完美區分，是線性可分的最直接證明。
