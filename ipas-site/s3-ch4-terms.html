第四章名詞解釋：機器學習與深度學習
30 個核心詞彙 · Machine Learning & Deep Learning
Supervised Learning
監督式學習
利用含有標籤(Labels)的訓練資料，學習輸入特徵到輸出目標的映射函數 f(x)→y。包含分類（離散輸出）與迴歸（連續輸出）兩大任務型態。
📌 情境給定歷史房價（含坪數、地段等特徵及實際售價），訓練模型預測新房屋價格。
⚡ 考題方向與非監督式學習的核心差異（有無標籤）；監督學習的訓練→驗證→測試流程。
Unsupervised Learning
非監督式學習
在無標籤資料中自動發現隱藏模式、結構或關係的技術。核心目標是讓模型自行組織、理解資料內在規律。包含聚類、降維、關聯規則與表示學習。
📌 情境電商平台將數百萬用戶按購買行為自動分群，發現高價值客群。
⚡ 考題方向非監督學習的評估難題（無標準答案）；常見方法：聚類、降維、關聯規則的適用場景。
Reinforcement Learning
強化式學習
RL
Agent 在環境(Environment)中透過執行行動(Action)獲得獎勵(Reward)訊號，學習最大化累積獎勵的策略(Policy)。無需預先標籤，透過試誤學習。
📌 情境AlphaGo 透過自我對弈強化學習，學習圍棋最優落子策略。
⚡ 考題方向MDP 五元素(S/A/R/P/γ)；策略梯度(Policy Gradient)vs.價值學習(Q-learning)的差異。
Markov Decision Process
馬可夫決策過程
MDP
強化學習的數學框架，由五元素構成：狀態S、行動A、轉移機率P、獎勵R、折扣因子γ。「馬可夫性質」指下一狀態只取決於當前狀態，與歷史無關。
📌 情境機器人導航問題可建模為MDP，每個位置為狀態，移動方向為行動，到達目標獲正獎勵。
⚡ 考題方向MDP 五元素的定義；馬可夫性質(無記憶性)；Value Function 與 Policy 的關係。
Linear Regression
線性迴歸
預測連續輸出的最基礎迴歸模型。公式：y=β₀+Σβᵢxᵢ+ε，透過最小二乘法(OLS)最小化殘差平方和(MSE)估計係數β。假設：線性關係、殘差常態分布、獨立同分布。
📌 情境預測廣告投放金額與銷售額的線性關係，建立簡單解釋性模型。
⚡ 考題方向OLS估計的前提假設；多重共線性問題；R²衡量模型解釋力；與Lasso/Ridge的關係。
Lasso Regression (L1)
Lasso 迴歸
L1
在線性迴歸損失函數加入L1正則化項 λΣ|βⱼ|。λ越大懲罰越強，會將部分係數壓縮至精確為零，實現自動特徵選擇（稀疏模型）。適合高維特徵且多數無關的情境。
📌 情境基因組資料含數萬個特徵，用Lasso自動篩選出真正影響疾病的少數基因。
⚡ 考題方向L1 vs. L2正則化的差異；Lasso能產生稀疏解做特徵選擇；λ超參數的調整效果。
Ridge Regression (L2)
Ridge 迴歸
L2
在損失函數加入L2正則化項 λΣβⱼ²。懲罰使所有係數均勻縮小但不為零，有效處理多重共線性問題。與Lasso不同，Ridge保留所有特徵但縮減係數。
📌 情境醫療預測中多個相關檢測指標存在共線性，用Ridge穩定模型係數估計。
⚡ 考題方向Ridge解決多共線性；L2不產生稀疏解；ElasticNet = Lasso+Ridge 結合兩者優點。
Support Vector Regression
支援向量迴歸
SVR
SVM 的迴歸版本。建立一個ε-不敏感管道，管道內的偏差不計入損失，只懲罰超出管道的點。C參數控制管道外點的懲罰程度，ε決定管道寬度。
📌 情境股價預測中允許小範圍誤差，SVR能建立穩健的非線性迴歸模型。
⚡ 考題方向ε-tube的作用；C參數與ε參數的調整效果；SVR可搭配核函數處理非線性資料。
Random Forest
隨機森林
RF
集成方法(Bagging)。透過Bootstrap抽樣建立多棵決策樹，並在每個節點隨機抽取部分特徵進行分裂，最終取平均（迴歸）或投票（分類）。抗過擬合，可輸出特徵重要性。
📌 情境信用風險評估中，隨機森林整合數百棵決策樹，提升預測穩定性與準確性。
⚡ 考題方向Bagging核心機制；Bootstrap抽樣的作用；特徵重要性計算；與單一決策樹的比較。
Gradient Boosting
梯度提升
GBM
Boosting集成方法。逐步建立弱學習器（通常是淺層決策樹），每棵新樹專門修正前一棵樹的殘差（梯度方向），透過加權求和得最終預測。學習率η控制每步步長。
📌 情境Kaggle競賽中梯度提升是最常見的致勝演算法，尤其在結構化表格資料上表現優異。
⚡ 考題方向Boosting降偏差(Bias)的原理；逐步修正殘差；與Bagging的本質差異；Early Stopping防過擬合。
eXtreme Gradient Boosting
XGBoost
XGB
梯度提升的高效實作，引入二階導數(Hessian)加速最佳分裂點搜尋，採用Level-wise（層級式）生長策略，內建L1/L2正則化、稀疏資料支援、缺值自動處理。
📌 情境廣告點擊率預測中XGBoost處理數百個特徵的大規模資料，訓練效率高且準確率優異。
⚡ 考題方向Level-wise(XGBoost)vs.Leaf-wise(LightGBM)生長策略；Hessian二階導數加速；正則化控制過擬合。
Light Gradient Boosting Machine
LightGBM
LGBM
梯度提升的高效版本，採用Leaf-wise（葉子式）分裂策略：每次選擇能帶來最大增益(max gain)的葉節點分裂。搭配Histogram-based演算法降低計算複雜度，大數據上速度更快。
📌 情境推薦系統中LightGBM在大規模用戶-商品特徵矩陣上訓練速度比XGBoost快數倍。
⚡ 考題方向Leaf-wise vs. Level-wise的差異與過擬合風險；Histogram-based加速；max_depth限制必要性。
Logistic Regression
邏輯迴歸
LR
雖名為「迴歸」，實際上是最基礎的分類演算法。透過Sigmoid函數將線性組合壓縮至(0,1)範圍，輸出類別機率。假設特徵與Log-Odds呈線性關係。公式：p=1/(1+e⁻(β₀+Σβᵢxᵢ))。
📌 情境銀行信用卡申請審核：輸出客戶違約機率，以0.5為閾值進行二元分類。
⚡ 考題方向Sigmoid函數的輸出範圍；Log-Odds(對數勝率)的意義；多類別需OvR或Multinomial擴展。
Support Vector Machine
支援向量機
SVM
在特徵空間中找到最大化兩類間距(Margin)的超平面決策邊界。決策邊界：w·x+b=0。邊界上的資料點稱為「支援向量」。軟間隔SVM用C參數容忍部分誤分類。
📌 情境人臉辨識中SVM尋找最佳超平面區分「人臉」與「非人臉」，在小資料集上表現良好。
⚡ 考題方向最大化Margin的原理；支援向量的定義；C參數作用；核函數如何處理非線性問題。
Kernel Function
核函數
Kernel
「核技巧(Kernel Trick)」：透過核函數K(xᵢ,x)=Φ(xᵢ)·Φ(x)隱式地將資料映射至高維空間，使線性不可分的資料變得線性可分，且無需顯式計算高維座標。常用：RBF核、多項式核。
📌 情境圓形分布資料在2D線性不可分，RBF核函數映射3D後即可用平面分開。
⚡ 考題方向核技巧的意義（避免顯式高維計算）；RBF/Linear/Polynomial核的適用場景；γ參數對RBF核的影響。
Decision Tree
決策樹
DT
透過一系列「如果…那麼…」規則遞迴分裂資料的樹狀模型。分裂準則：基尼不純度(Gini)或資訊增益(Information Gain)。優點：直觀可解釋；缺點：易過擬合，對資料微小變動敏感。
📌 情境醫療診斷系統中，決策樹的規則直觀：「發燒>38.5且咳嗽→疑似流感」。
⚡ 考題方向Gini vs. 資訊增益的分裂標準；max_depth/min_samples_split防過擬合；單棵樹vs.集成方法的比較。
Gini Impurity
基尼不純度
Gini
衡量節點混雜程度的指標，用於決策樹分裂標準。公式：G = 1 - Σpᵢ²。G=0表示節點完全純淨（只有一種類別），G=0.5（二分類等比）表示最混雜。決策樹選擇能最大降低Gini的特徵分裂。
📌 情境分裂前節點有50%好瓜/50%壞瓜(G=0.5)，分裂後左子節點90%好瓜(G=0.18)，右子節點80%壞瓜(G=0.32)，整體不純度下降。
⚡ 考題方向Gini公式計算；與資訊增益(Entropy)的比較；G值越小越好；CART演算法使用Gini。
K Nearest Neighbors
K最近鄰分類
KNN
非參數、惰性學習(Lazy Learning)演算法。無需建立顯式模型，預測時計算新樣本與所有訓練樣本的距離，找出K個最近鄰，以多數投票（分類）或取均值（迴歸）決定輸出。
📌 情境推薦系統中「與你最相似的3位用戶喜歡X電影」，即KNN的直覺概念。
⚡ 考題方向K值選擇的影響（太小易過擬合，太大邊界模糊）；維度詛咒；需特徵標準化；惰性學習的特點。
Naïve Bayes Classifier
樸素貝氏分類
NB
基於貝氏定理，假設所有特徵在給定類別條件下彼此獨立（「樸素」假設）。雖然現實中獨立性幾乎不完全成立，但在文本分類等場景效果良好，且計算快速、可即時更新。
📌 情境垃圾郵件過濾：計算出現「優惠」「領獎」等詞彙條件下，郵件為垃圾信的後驗機率。
⚡ 考題方向樸素假設的含義；零機率問題與Laplace平滑解決方法；適用文本分類、即時預測場景。
k-means Clustering
k-means 分群
k-means
最常用的聚類演算法。預設K個群集，隨機初始化質心，迭代執行：①分配每個點至最近質心→②重新計算質心，直到收斂。需預先指定K值，對初始質心敏感，只能處理凸形群集。
📌 情境將全球10萬家零售門市按銷售特徵自動分為K個群組，指導差異化行銷策略。
⚡ 考題方向需預設K值（Elbow Method選K）；對離群值敏感；只能處理凸形群集；vs. DBSCAN的核心差異。
Density-Based Spatial Clustering
DBSCAN
DBSCAN
基於密度的聚類演算法，以ε（鄰域半徑）和MinPts（最少點數）定義核心點、邊界點和雜訊點。無需預設K值，能發現任意形狀群集，並自動識別離群值（雜訊點）。
📌 情境地圖上餐廳位置聚類：DBSCAN能發現不規則形狀的商圈，並標記偏遠孤立餐廳為異常點。
⚡ 考題方向不需預設K、能識別雜訊點、處理任意形狀群集（vs.k-means只能凸形）；ε與MinPts的調整影響。
Hierarchical Clustering
階層式分群
HC
以樹狀圖(Dendrogram)呈現資料點的相似層次結構。凝聚式(bottom-up)：從每點各自為群逐步合併；分裂式(top-down)：從整體逐步分裂。不需預先指定K值，可後期截斷Dendrogram決定K。
📌 情境生物學中以基因表現相似性建立物種進化樹，Dendrogram呈現親緣關係層次。
⚡ 考題方向凝聚式vs.分裂式；Dendrogram的讀法與截斷選K；計算複雜度O(n²)；鏈結準則（Single/Complete/Average）。
Artificial Neural Network
人工神經網路
ANN
模仿生物神經元連接的計算模型。由輸入層、隱藏層、輸出層組成，每個神經元計算加權和再經激活函數輸出：z=Σwᵢxᵢ+b，a=σ(z)。多層疊加賦予強大的非線性表示能力。
📌 情境三層神經網路學習手寫數字辨識：輸入784像素→隱藏層特徵提取→輸出10類機率。
⚡ 考題方向前向傳播(Forward Propagation)計算流程；激活函數(ReLU/Sigmoid/Tanh)的作用；深度vs.寬度的影響。
Convolutional Neural Network
卷積神經網路
CNN
專為處理網格狀資料（影像）設計的深度學習架構。卷積層(Conv)以小型濾波器掃描，實現局部感受野與參數共享；池化層(Pooling)降維保留主要特徵；全連接層(FC)完成最終分類。
📌 情境醫療影像AI：CNN自動學習X光片中腫瘤的形狀、紋理特徵，協助醫師診斷。
⚡ 考題方向局部感受野與參數共享的優勢；Conv/Pool/FC各層作用；適用場景：影像分類/物件偵測/分割。
Recurrent Neural Network
循環神經網路
RNN
專為處理序列資料設計的神經網路，每個時間步的隱藏狀態hₜ = f(xₜ, hₜ₋₁)，將前一步的隱藏狀態傳遞至下一步，實現「記憶」。缺點：長序列中存在梯度消失/爆炸問題。
📌 情境文字生成模型中RNN逐字預測下一個詞，利用之前詞彙的上下文隱藏狀態。
⚡ 考題方向隱藏狀態傳遞的機制；梯度消失問題（長序列）；BPTT（時間反向傳播）；RNN→LSTM改進方向。
Long Short-Term Memory
長短期記憶網路
LSTM
RNN的改進版，透過三個閘門解決梯度消失問題：遺忘閘(Forget Gate)決定丟棄舊記憶、輸入閘(Input Gate)決定寫入新記憶、輸出閘(Output Gate)決定輸出。同時維護Cell State(長期記憶)與Hidden State。
📌 情境機器翻譯中LSTM能記憶長距離的句子結構，如記住句子開頭的主語以正確生成動詞時態。
⚡ 考題方向三個閘門的功能；Cell State(長期記憶)vs. Hidden State(短期記憶)；LSTM解決梯度消失的機制；GRU的簡化版本。
Transformer
Transformer 架構
Attn
完全基於自注意力機制(Self-Attention)的架構，拋棄RNN的序列處理，能並行計算全序列的依賴關係。由Encoder（理解輸入）與Decoder（生成輸出）組成，加入位置編碼補充序列順序資訊。
📌 情境GPT系列語言模型、BERT文本理解模型皆以Transformer為基礎，成為現代NLP的核心架構。
⚡ 考題方向Self-Attention的計算(Q/K/V)；位置編碼的必要性；Encoder-only(BERT)/Decoder-only(GPT)的差異；並行計算優勢。
Attention Mechanism
注意力機制
Attn
讓模型在處理某位置時，動態關注序列中最相關的其他位置的機制。透過計算Query(Q)、Key(K)、Value(V)：Attention=softmax(QKᵀ/√dₖ)·V，得到上下文感知的表示向量。
📌 情境翻譯「The cat sat on the mat」時，處理「cat」位置時，模型對「mat」的注意力權重也較高（語意關聯）。
⚡ 考題方向Q/K/V的角色；√dₖ縮放的目的（防Softmax梯度消失）；Multi-Head Attention的多視角優勢。
Batch Normalization
批次正規化
BN
在神經網路的層之間加入的正規化操作。對每個批次的輸入計算均值與方差，將其標準化為均值0、方差1，再乘以可學習的縮放(γ)和偏移(β)。加速訓練收斂、緩解梯度問題、具輕微正則化效果。
📌 情境深層CNN訓練中加入BN後，可使用更大學習率，訓練速度顯著提升且更穩定。
⚡ 考題方向BN的作用：加速收斂、防Internal Covariate Shift；γ/β的可學習性；訓練vs.推理階段的差異（使用全局統計量）。
Dropout
Dropout 正則化
Drop
訓練時隨機丟棄(置零)部分神經元（以概率p），防止神經元之間產生共適應(Co-adaptation)，迫使網路學習更魯棒的特徵表示。推理時使用所有神經元但乘以(1-p)。等效於訓練多個子網路的集成。
📌 情境深度神經網路訓練時加入Dropout(p=0.5)，有效減少過擬合，提升在測試集上的泛化性能。
⚡ 考題方向Dropout防過擬合的原理；訓練vs.推理的行為差異；p值選擇（通常0.2~0.5）；與L2正則化的比較。
