Overfitting / Underfitting
過擬合 / 欠擬合

核心概念：描述模型「泛化能力」好壞的兩個極端——過度學習訓練資料（過擬合）或學習不足（欠擬合）。

目標：找到剛好夠複雜的模型，訓練誤差和測試誤差都低，具備良好泛化能力。

白話理解
💡 欠擬合（Underfitting）：就像只背公式、不理解概念的學生，連基本題都做錯。模型太簡單，訓練誤差也高。

過擬合（Overfitting）：死背考古題的學生，換道新題就崩潰。模型記住了訓練資料的雜訊，在測試集誤差高。
三種擬合狀況
診斷方法
欠擬合：Train Error ↑ Test Error ↑
正常：Train Error ↓ Test Error ↓
過擬合：Train Error ↓ Test Error ↑↑
Gap：泛化誤差 = Test − Train
• 學習曲線（Learning Curve）是診斷最佳工具
• 驗證集誤差持續高於訓練集 → 過擬合
解決對策
欠擬合 → 增加複雜度
• 增加特徵 / 多項式特徵
• 加深加寬神經網路
• 減少正則化強度
過擬合 → 降低複雜度 / 增加資料
• 更多訓練資料 / 資料增強
• L1/L2 正則化 / Dropout
• Early Stopping / 交叉驗證
🔍 考試關鍵字
  • 泛化誤差（Generalization Error）
  • 訓練誤差 / 測試誤差
  • 學習曲線（Learning Curve）
  • 模型複雜度（Model Complexity）
  • 正則化 / Dropout / Early Stopping
⭐ 必記口訣
  • 訓練差 → 欠擬合（模型太弱）
  • 訓練好 + 測試差 → 過擬合
  • 資料少 → 容易過擬合
  • 特徵多 → 容易過擬合
  • 正則化降低 Variance，提高 Bias
小提醒
  1. 學習曲線是最直觀的診斷工具：訓練集與驗證集誤差的差距就是過擬合程度。
  2. 神經網路中，Dropout（訓練時隨機關閉神經元）是最常用的過擬合對策。
  3. 過擬合不一定要減少層數，加 L2 正則化（Weight Decay）往往更有效。

Bias / Variance Tradeoff
偏差 / 變異數 權衡

核心概念：模型誤差的兩個來源——偏差（Bias）是模型本身的錯誤假設；變異數（Variance）是模型對訓練資料的敏感程度。

目標：理解 Bias-Variance Tradeoff，找到最佳模型複雜度，讓總誤差最小。

白話理解
💡 用射箭靶比喻：
High Bias：每次都偏同一方向（系統性錯誤）
High Variance：每次都落很散（不穩定）
最理想：Low Bias + Low Variance（集中在靶心）

增加模型複雜度→降 Bias、升 Variance；
正則化/簡化模型→降 Variance、升 Bias。
靶心示意
數學分解
誤差：E[(y−ŷ)²] = Bias² + Var + ε²
Bias²：(E[ŷ]−f(x))²（系統性偏差）
Variance：E[(ŷ−E[ŷ])²]（波動性）
ε²：不可消除雜訊（Irreducible Error）
• Bias ↑ ↔ 欠擬合 / 模型太簡單
• Variance ↑ ↔ 過擬合 / 模型太複雜
常見模型 Bias-Variance
High Bias：線性迴歸、Naive Bayes、決策樹（淺）
High Variance：深度神經網路、決策樹（深）、KNN（k小）
中間平衡：Random Forest（Bagging → 降Variance）
中間平衡：Gradient Boosting（→ 降Bias）
🔍 考試關鍵字
  • Bias（偏差）/ Variance（變異數）
  • Bias-Variance Tradeoff
  • 不可消除雜訊（Irreducible Error）
  • Bagging → 降 Variance
  • Boosting → 降 Bias
⭐ 對應解法
  • High Bias → 增加特徵、複雜化模型
  • High Variance → 更多資料、正則化
  • Bagging（如 Random Forest）降低 Variance
  • Boosting（如 XGBoost）降低 Bias
  • 交叉驗證診斷兩者哪個更嚴重
小提醒
  1. 這是 ML 最核心的概念。考試常問：「增加訓練資料能解決哪個問題？」→ High Variance（過擬合），無法解決 High Bias。
  2. Ensemble 方法：Bagging 靠平均多個高 Variance 模型來降低 Variance；Boosting 靠逐步修正誤差降低 Bias。

L1 / L2 Regularization
L1 / L2 正則化

用途：防止模型過擬合，約束模型權重，提升泛化能力

目標：在損失函數中加入懲罰項，使模型偏好較小的權重值，降低模型複雜度。

白話理解
💡 L2（Ridge）：像彈簧，把所有權重往 0 拉，但沒有一個會真正歸零——讓每個特徵都發揮一點作用。

L1（Lasso）：更激進，會把不重要的權重直接歸零——自動做特徵選擇！

ElasticNet：L1 + L2 兩者混合。
幾何直觀（約束空間）
L1 vs L2 vs ElasticNet 比較
名稱懲罰項效果適用場景
L1 / LassoλΣ|wᵢ|稀疏解，部分 w=0特徵選擇、高維稀疏資料
L2 / RidgeλΣwᵢ²均勻縮小，w≠0多重共線性、通用首選
ElasticNetλ₁Σ|wᵢ|+λ₂Σwᵢ²兩者兼具特徵多且相關時
🔍 考試關鍵字
  • L1 正則化 / Lasso / 稀疏解
  • L2 正則化 / Ridge / Weight Decay
  • 懲罰項（Penalty Term）
  • 超參數 λ（正則化強度）
  • ElasticNet
⭐ 選哪個正則化？
  • 需要特徵選擇 → L1 (Lasso)
  • 特徵都有用，避免 Overfit → L2
  • 特徵多且相關 → ElasticNet
  • 深度學習 → L2（Weight Decay）
  • 所有模型都適用，預設試 L2
小提醒
  1. L1 → 特徵選擇（稀疏解，部分係數歸零）；L2 → 防止 Overfit（不歸零，均勻縮小）。
  2. 正則化強度 λ 越大，懲罰越重，模型越簡單（Bias↑, Variance↓）。
  3. Deep Learning 中的 L2 即 Weight Decay（在 optimizer 中設置 weight_decay 參數）。

Cross Validation
交叉驗證

用途：可靠評估模型效能、超參數調整、防止評估過度樂觀

目標：充分利用有限資料，讓每一筆資料都當過驗證集，得到更穩健的效能估計。

白話理解
💡 想像輪班考試監考：
把資料切成 K 等份，每次讓一份當「考官（驗證集）」，其餘 K-1 份當「訓練資料」。
跑 K 次，每份都當過一次考官，最後平均 K 次結果作為最終評分。

比單次 train/test split 更可靠，減少評估的運氣成分。
K-Fold 示意（K=5）
交叉驗證方法比較
方法特點適用場景
K-Fold (K=5/10)K 次訓練，均衡評估最常用，通用首選
Stratified K-Fold每折保持類別比例類別不平衡問題
Leave-One-Out (LOO)每次只留一筆驗證，最精確極小資料集（<100筆）
Time Series Split只用過去預測未來，不洩漏時間序列資料
🔍 考試關鍵字
  • K-Fold Cross Validation
  • Stratified K-Fold（分層取樣）
  • Leave-One-Out (LOO/LOOCV)
  • 資料洩漏（Data Leakage）
  • 泛化估計（Generalization Estimate）
⭐ 什麼情境適合用？
  • 資料量有限（<10,000筆）
  • 超參數搜索（Grid Search + CV）
  • 比較不同模型效能
  • 類別不平衡 → Stratified
  • 時間序列 → Time Series Split
小提醒
  1. Preprocessing 必須在 CV 的 loop 內，不能先對全資料 fit（否則測試集資訊洩漏）！用 sklearn 的 Pipeline 可以自動處理。
  2. 一般資料 K=5 或 K=10；類別不平衡一定用 StratifiedKFold。
  3. 時間序列絕對不能用隨機 K-Fold，要用 TimeSeriesSplit。

Confusion Matrix
混淆矩陣

用途：分類模型評估，呈現預測結果與真實標籤的詳細對應關係

目標：一目了然地看出模型把哪些類別搞混，以及各種錯誤的分布。

白話理解
💡 以疾病篩檢為例：
TP（真陽性）：有病，正確判為有病 ✅
TN（真陰性）：無病，正確判為無病 ✅
FP（假陽性）：無病，誤判為有病 😟
FN（假陰性）：有病，誤判為無病 ⚠️（最危險！）
2×2 混淆矩陣
衍生指標公式
Accuracy：(TP+TN) / (TP+FP+FN+TN)
Precision：TP / (TP + FP)
Recall：TP / (TP + FN)
F1：2×P×R / (P + R)
Specificity：TN / (TN + FP)
FP vs FN 的成本取捨
假陰性（FN）代價高 → 提高 Recall
例：癌症篩檢（漏掉患者最危險）
假陽性（FP）代價高 → 提高 Precision
例：垃圾信（誤刪正常信件）
兩者平衡 → 用 F1 Score
例：一般分類任務評估
🔍 考試關鍵字
  • TP / TN / FP / FN 定義
  • Type I Error = FP（誤報）
  • Type II Error = FN（漏報）
  • ROC Curve / AUC
  • Precision-Recall Curve
⭐ 使用時機
  • 任何分類任務都應先看混淆矩陣
  • 類別不平衡時比 Accuracy 更有意義
  • 診斷模型哪些類別容易混淆
  • 選擇最佳分類閾值（Threshold）
小提醒
  1. 類別不平衡（如 99% 負例）時，Accuracy 沒有意義！模型全猜負例 Acc=99% 但 Recall=0%。
  2. AUC-ROC：考慮所有閾值下的 TPR vs FPR，值越接近 1 越好（隨機猜測=0.5）。
  3. 醫療診斷首看 Recall（靈敏度）；刑事司法首看 Precision（精確度）。
20
Accuracy / Precision / Recall / F1
準確率 / 精確率 / 召回率 / F1

用途：分類模型效能指標，衡量模型「預測對了多少」以及「找到了多少目標」

目標：根據任務需求選擇最合適的指標，避免被不適合的指標誤導（如類別不平衡時的 Accuracy）。

白話理解（Venn 圖）
指標定義與直覺
Accuracy：(TP+TN) / All
整體猜對比例，類別不平衡時慎用
Precision：TP / (TP+FP)
「預測為正的中，真的有多少是正的」
Recall：TP / (TP+FN)
「所有真正的正例中，找到了多少」
F1：2PR / (P+R)（調和平均）
Precision 和 Recall 的平衡指標
指標選擇指南
場景最重要的指標原因
癌症 / 疾病篩檢Recall（召回率）漏掉患者（FN）代價極高
垃圾信件過濾Precision（精確率）誤刪正常信（FP）代價高
類別不平衡F1 Score / AUCAccuracy 失去意義
多類別分類Macro/Weighted F1平均各類別 F1，更全面
🔍 考試關鍵字
  • Precision = 查準率（精確率）
  • Recall = 查全率（靈敏度）
  • F1 = 調和平均（Harmonic Mean）
  • Macro / Micro / Weighted Average
  • Precision-Recall Tradeoff
⭐ Precision-Recall 取捨
  • 降低分類閾值 → Recall↑, Precision↓
  • 提高分類閾值 → Precision↑, Recall↓
  • Fβ：β>1 偏重 Recall（醫療）
  • Fβ：β<1 偏重 Precision（搜尋）
小提醒
  1. 必考口訣：Precision = 預測為正的命中率；Recall = 實際正例的找到率。
  2. 類別不平衡時，不要看 Accuracy！看 F1 或 AUC-ROC。
  3. 多類別：Macro F1（各類別等權重）vs Weighted F1（按樣本數加權）——類別不平衡用 Weighted。

MAE / MSE / RMSE / R²
迴歸評估指標

用途：評估迴歸模型預測連續數值的效能

目標：量化預測值與真實值之間的差距，理解不同指標對離群值的敏感度差異。

白話理解
💡 用射箭比喻（連續距離）：
MAE：每次偏差的絕對值平均——「平均差多遠」
MSE：偏差的平方平均——大偏差懲罰更重
RMSE：MSE 開根號，單位與原本相同
R²：模型解釋了多少變異（0~1，越高越好）
殘差示意
四大指標比較
指標公式單位離群值敏感度主要用途
MAE (1/n)Σ|yᵢ−ŷᵢ|同 y低（穩健）離群值多時首選
MSE (1/n)Σ(yᵢ−ŷᵢ)²y²高訓練損失函數
RMSE √MSE同 y高最常用評估指標
R² 1−SS_res/SS_tot無（0~1）中模型解釋力（可比較）
數學細節
MAE：(1/n) Σᵢ|yᵢ − ŷᵢ|
MSE：(1/n) Σᵢ(yᵢ − ŷᵢ)²
RMSE：√[(1/n) Σᵢ(yᵢ − ŷᵢ)²]
R²：1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−ȳ)²
• R²=1：完美預測；R²=0：與平均值一樣；R²<0：比猜平均更差
例子：房價預測

預測 vs 實際

  • 預測：800 萬
  • 實際：750 萬
  • 誤差：50 萬
→

指標

= 72 萬

🔍 考試關鍵字
  • MAE（平均絕對誤差）
  • MSE（均方誤差）
  • RMSE（均方根誤差）
  • R²（決定係數 / 解釋變異比例）
  • SS_res（殘差平方和）/ SS_tot
⭐ 如何選擇指標？
  • 大誤差代價高 → RMSE（放大懲罰）
  • 離群值多 → MAE（更穩健）
  • 想知道解釋力 → R²
  • 訓練損失用 MSE（可微分）
  • 比較不同量綱模型 → R²（無單位）
小提醒
  1. RMSE > MAE 代表資料中有大誤差的離群值；差距越大，離群值越嚴重。
  2. R² 在多元迴歸中會隨特徵數增加而虛假升高，應改看 Adjusted R²。
  3. R² 可為負值（若模型比猜平均更差），這表示模型選錯了。
  4. Huber Loss：MAE 與 MSE 的折衷，對離群值有部分抵抗力。
