資料類型 · 大數據特性 · 資料庫
最基礎、最高頻的考點群
資料三分類
  • 結構化：關聯式資料庫表格（SQL），固定 Schema，易查詢
  • 半結構化：JSON / XML / CSV，有標籤但不固定格式
  • 非結構化：圖片、影片、音訊、自然語言，佔真實世界 80%+
大數據 5V
  • Volume（量）：資料規模大（TB/PB 級）
  • Velocity（速）：產生與處理速度快（串流）
  • Variety（類）：多種資料格式並存
  • Veracity（真）：資料品質與可信度
  • Value（值）：從資料中萃取商業價值
資料庫類型對比
類型特性代表
RDBMSACID、固定Schema、SQL查詢MySQL, PostgreSQL
文件型JSON彈性文件、水平擴展MongoDB
KV Store超低延遲、快取首選Redis
列族型寫入密集、時序適合Cassandra, HBase
圖資料庫關係網路、知識圖譜Neo4j
⚡ 考試常見陷阱
  • OLTP vs OLAP：OLTP（線上交易處理，寫入頻繁，行式儲存）；OLAP（線上分析處理，讀取為主，列式儲存，適合 DW）
  • 資料倉儲 vs 資料湖 vs 湖倉一體：DW（結構化+歷史，慢但可靠）；Data Lake（原始資料，低成本）；Lakehouse（兩者優點，Delta Lake/Iceberg）
  • 5V 中 Value 常被考：不是資料本身的值，而是「能否從資料中萃取商業價值」
ETL / ELT · 資料清理 · 統計基礎
流程概念 + 技術名詞，考題偏選擇題場景判斷
ETL vs ELT
  • ETL（Extract→Transform→Load）：先轉換再入庫，適合傳統 DW，對目標資料庫壓力小
  • ELT（Extract→Load→Transform）：先入庫再轉換，適合雲端 Data Lake，利用雲算力
  • Data Pipeline：自動化的資料流程，涵蓋擷取、清理、轉換、存儲各步驟
  • Apache Kafka：高吞吐量訊息佇列，適合即時串流資料管線
統計基礎
  • 描述統計：平均數（受異常值影響）、中位數（穩健）、眾數、標準差、IQR
  • 偏態：右偏（長尾在右，均值＞中位數）；左偏（長尾在左）
  • 相關係數：Pearson（線性）；Spearman（非線性/順序）；−1~+1，0 表示無線性相關
  • 常態分佈：68-95-99.7 法則（1σ/2σ/3σ 範圍）
資料清理技術
  • 遺漏值：均值填補（MCAR）、中位數（偏態分佈）、前後向填補（時序）、KNN填補、刪除（少量缺失）
  • 異常值偵測：Z-score（|Z|＞3 視為異常）、IQR 法（Q1−1.5×IQR ~ Q3+1.5×IQR）、Isolation Forest、LOF
  • 重複值：drop_duplicates，保留首筆或最新筆
  • 資料一致性：格式標準化（日期/電話）、單位統一（元/千元）
大數據框架
  • Hadoop：HDFS（分散式儲存）+ MapReduce（批次處理），適合大量離線分析
  • Apache Spark：In-memory 計算，比 MapReduce 快 100×，支援批次+串流（Spark Streaming）
  • Kafka：訊息佇列，Pub/Sub 模式，毫秒級延遲串流
⚡ 考試常見陷阱
  • ETL vs ELT 選哪個？場景：資料湖 + 雲端計算 → ELT；傳統企業 DW + 嚴格品質管控 → ETL
  • 中位數 vs 均值：資料有明顯異常值時，用中位數填補更穩健；薪資分佈、房價等右偏資料用中位數
  • Spark vs Hadoop：Spark 是 Hadoop 的加速版，不取代 HDFS；Spark 需要更多記憶體

三大範式 · 偏差-變異數 · 正則化
概念理解題，考的是「選哪種方法」的判斷
三大學習範式
  • 監督式：有標籤資料（X, y）→ 預測 y。迴歸（連續）/ 分類（離散）
  • 非監督式：無標籤 → 發現結構。聚類（K-means）/ 降維（PCA）/ 異常偵測
  • 強化學習：Agent 與環境互動，最大化累積獎勵。代表：AlphaGo、機器人控制
  • 半監督：少量標籤 + 大量無標籤，如 SSL（Self-supervised Learning）
偏差-變異數權衡
  • 高偏差（Bias）＝ 欠擬合（Underfitting），模型太簡單，訓練/驗證誤差都高
  • 高變異（Variance）＝ 過擬合（Overfitting），訓練誤差低但驗證誤差高
  • 改善欠擬合：增加特徵、增加模型複雜度、減少正則化
  • 改善過擬合：更多資料、正則化、Dropout、早停（Early Stopping）、集成學習
正則化三兄弟
方法懲罰項效果適用
L1（Lasso）Σ|w|稀疏解（特徵歸零）特徵選擇
L2（Ridge）Σw²權重均勻縮小多重共線性
Elastic NetL1+L2兩者折衷高維稀疏
Dropout隨機關閉神經元降過擬合深度學習
集成學習
  • Bagging（並行）：多棵決策樹投票，代表：Random Forest，降低 Variance
  • Boosting（串行）：後棵修正前棵錯誤，代表：XGBoost / AdaBoost / LightGBM，降低 Bias
  • Stacking：用 meta-learner 整合多個基模型的預測
評估指標 · 混淆矩陣 · 超參數調優
計算題 + 場景判斷題，考試最高頻區域
混淆矩陣四象限
預測 Positive預測 Negative
實際 PositiveTP（True Pos）FN（漏報）
實際 NegativeFP（誤報）TN（True Neg）
  • Accuracy ＝ (TP+TN) / Total，類別不平衡時失真
  • Precision ＝ TP/(TP+FP)，「預測為正中真正是正的比率」→ 重視 FP（詐欺偵測）
  • Recall ＝ TP/(TP+FN)，「真正為正中被抓出的比率」→ 重視 FN（癌症篩查）
  • F1 Score ＝ 2×P×R/(P+R)，Precision 與 Recall 的調和平均
  • AUC-ROC：ROC 曲線（TPR vs FPR）下面積；AUC=1 完美，=0.5 等同隨機
超參數調優
  • Grid Search：窮舉所有參數組合，計算成本高但系統
  • Random Search：隨機採樣，效率較高，大參數空間常用
  • Bayesian Optimization：用代理模型預測最佳參數，最有效率
  • k-fold 交叉驗證：資料切 k 份，輪流驗證，最終取平均，避免單次分割偏差
類別不平衡處理
  • SMOTE：過採樣（Oversampling），合成少數類新樣本
  • 下採樣（Undersampling）：減少多數類樣本
  • 加權損失函數：給少數類更高的損失權重
  • 評估指標：不平衡時用 F1 / AUC，不用 Accuracy
⚡ 考試最常混淆的地方
  • Precision vs Recall 選哪個？ 癌症/疾病篩查（漏報代價高）→ Recall；垃圾郵件（誤判代價高）→ Precision
  • Random Forest vs XGBoost：RF = Bagging（並行，抗過擬合）；XGB = Boosting（串行，準確率高但易過擬合）
  • L1 vs L2 選哪個？ 特徵多、可能有無關特徵 → L1（Lasso，稀疏）；特徵都有意義但多重共線性 → L2（Ridge）
  • 訓練/驗證/測試集的角色：驗證集調超參數；測試集是最終評估，不可用於任何訓練決策

No-code / Low-code AI 工具
  • Make（Integromat）/ Zapier：視覺化自動化工作流，整合 100+ 應用
  • Bubble / Webflow：無代碼建構 Web App
  • Google AutoML / Azure ML Studio：拖拉式模型訓練
  • 特性：快速上線、降低技術門檻、缺乏深度客製彈性
RAG 架構（Retrieval-Augmented Generation）
  • 問題：LLM 知識截止日期（Knowledge Cutoff）、幻覺（Hallucination）
  • RAG 解法：查詢 → 向量搜尋外部知識庫 → 取回相關文件 → LLM 整合生成
  • 向量資料庫：Pinecone, Weaviate, Chroma, Milvus（儲存文本嵌入向量）
  • 優點：無需重訓練即可更新知識、降低幻覺、可引用來源
AI Agent 框架
  • LangChain：LLM 應用開發框架，鏈式呼叫、工具整合
  • AutoGPT / CrewAI：多 Agent 協作框架，任務分解與自動執行
  • Tool Use：LLM 呼叫外部工具（搜尋引擎、計算機、API）完成任務
  • MCP（Model Context Protocol）：標準化 Agent 與工具連接協議
⚡ 考試提示
  • RAG vs Fine-tuning 選哪個？ 知識需常更新 → RAG；需要特定語氣/風格 → Fine-tuning；兩者不互斥
  • Prompt Engineering 三層：Zero-shot（直接問）→ Few-shot（給範例）→ Chain-of-Thought（要求逐步推理）
  • 向量資料庫 ≠ 一般資料庫：儲存 Embedding 向量，以相似度（cosine / 歐式距離）搜尋，非關鍵字比對
