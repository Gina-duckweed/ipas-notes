4.1 原理與技術
Learning Paradigms
監督式學習：有標籤資料→學習映射函數分類/迴歸
非監督式學習：無標籤→發現結構聚類/降維
強化式學習：Agent與環境互動獲RewardMDP
特徵空間：所有特徵構成的高維空間
損失函數：MSE / MAE / Cross-Entropy
評估指標：Acc / Precision / Recall / F1 / R²
4.2 迴歸演算法
Regression Algorithms
線性迴歸：y=β₀+Σβᵢxᵢ+ε，OLS最小化MSE
Lasso (L1)：+λΣ|βⱼ| 稀疏化，特徵選擇
Ridge (L2)：+λΣβⱼ² 縮減係數，多共線
SVR：ε-不敏感管道，C控制懲罰
隨機森林：Bootstrap+投票，抗過擬合
XGBoost/LightGBM：梯度提升高效版
4.2 分類演算法
Classification Algorithms
邏輯迴歸：Sigmoid輸出機率，線性邊界
SVM：最大化Margin，核函數非線性
決策樹：Gini/Entropy分裂，可解釋
KNN：K個最近鄰投票，惰性學習
樸素貝氏：條件獨立假設，文本分類
集成分類：Bagging降變異/Boosting降偏差
非監督演算法 · 聚類方法
Centroid-based
k-means 分群
預設K個質心，迭代分配→更新，需先指定K值。對初始質心敏感，只能處理凸形群集。
Density-based
DBSCAN
以密度可達定義群集，不需預設K值，可發現任意形狀群集，自動辨識雜訊點（離群值）。
Hierarchical
階層式分群
凝聚式(bottom-up)或分裂式(top-down)，產生樹狀圖(Dendrogram)，不需預設K值。
Dimensionality
降維方法
PCA(線性), t-SNE/UMAP(非線性視覺化), Autoencoder(學習壓縮表示)用於資料探索與視覺化。
Association
關聯規則
Apriori/FP-Growth挖掘頻繁項目集，計算支持度(Support)、信賴度(Confidence)、提升度(Lift)。
Evaluation
聚類評估
Silhouette Score（群內緊密/群間分離）、Davies-Bouldin Index、Reconstruction Error（降維）。

4.3 深度學習框架與核心架構
CNN 卷積神經網路
Convolutional Neural Network
  • 卷積層(Conv)：局部感受野，參數共享
  • 池化層(Pooling)：降維，提取主要特徵
  • 全連接層：最終分類/迴歸輸出
  • 適用：影像辨識、物件偵測、醫學影像
RNN / LSTM
Recurrent Network / Long Short-Term Memory
  • RNN：處理序列資料，隱藏狀態傳遞記憶
  • LSTM：記憶閘(Input/Forget/Output Gate)解決梯度消失
  • GRU：LSTM簡化版，更新門+重置門
  • 適用：NLP、時間序列、語音辨識
Transformer
Self-Attention Architecture
  • 自注意力(Self-Attention)：捕捉全局依賴關係
  • Multi-Head Attention：並行多組注意力
  • 位置編碼(Positional Encoding)：補充序列順序資訊
  • 基礎：BERT、GPT、Vision Transformer(ViT)
訓練技術與框架
Training Techniques & Frameworks
  • Batch Normalization：層內標準化穩定訓練
  • Dropout：隨機丟棄神經元防過擬合
  • 反向傳播(Backpropagation)：鏈式法則計算梯度
  • 框架：PyTorch(動態圖) / TensorFlow(靜態+動態)
