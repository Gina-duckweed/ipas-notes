基本語法與型別

變數賦值與命名 variable

Python 為動態型別語言,變數不須宣告型別,賦值即建立。

name = "Gina"          # 字串
age = 28                # 整數
height = 168.5          # 浮點數
is_active = True        # 布林值

# 多重賦值
x, y, z = 1, 2, 3
a = b = c = 0

# 交換變數(不需暫存變數)
x, y = y, x

常見資料型別 type

Python 的內建基礎型別:int、float、str、bool、None。

type(10)        # <class 'int'>
type(3.14)      # <class 'float'>
type("hi")      # <class 'str'>
type(True)      # <class 'bool'>
type(None)      # <class 'NoneType'>

x = None        # 代表「沒有值」
if x is None:
    print("尚未賦值")

型別轉換 cast

使用 int()、float()、str()、bool() 等函式在型別間轉換。

int("42")        # 42
float("3.14")    # 3.14
str(100)         # "100"
bool(0)          # False
bool("")         # False
bool("a")        # True
list("abc")      # ['a', 'b', 'c']
int(3.9)         # 3 (無條件捨去)

字串格式化 f-string str

f-string(f"...")是目前最建議的字串格式化方式,可直接內嵌運算式。

name, score = "Gina", 92.567

f"{name} 得了 {score} 分"
# 'Gina 得了 92.567 分'

f"{score:.1f}"        # 保留一位小數 -> '92.6'
f"{score:>10.2f}"     # 靠右對齊,寬度10
f"{name!r}"           # 使用 repr() -> "'Gina'"
f"{1000000:,}"        # 千分位 -> '1,000,000'

字串常用方法 str

字串是不可變(immutable)物件,常用方法會回傳新字串。

s = "  Hello, Python World  "

s.strip()              # 去除頭尾空白
s.lower()               # 全小寫
s.upper()               # 全大寫
s.replace("Python", "AI")
s.split(",")            # 依逗號切割成 list
"-".join(["a","b","c"]) # 'a-b-c'
s.startswith("  He")    # True
"py" in s.lower()       # True

字串切片 Slicing str

以 [起始:結束:步長] 取出序列的子集合,適用於 str、list、tuple。

s = "Python"

s[0]        # 'P'  第一個字元
s[-1]       # 'n'  最後一個字元
s[0:3]      # 'Pyt' 索引0到2
s[:3]       # 'Pyt' 省略起始
s[3:]       # 'hon' 省略結束
s[::-1]     # 'nohtyP' 反轉字串
s[::2]      # 'Pto' 每隔一個取一次

運算子總覽 operator

算術、比較、邏輯、指派運算子是撰寫條件與運算的基礎。

# 算術: +  -  *  /  //(整除)  %(餘數)  **(次方)
7 // 2   # 3
7 % 2    # 1
2 ** 10  # 1024

# 比較: ==  !=  >  <  >=  <=
# 邏輯: and  or  not
(3 > 2) and (5 > 1)   # True

# 指派: +=  -=  *=  /=  //=  **=
x = 10
x += 5   # x = 15

流程控制

if / elif / else control

依縮排(通常4個空白)決定程式碼區塊,不使用大括號。

score = 78

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

print(grade)   # C

for 迴圈與 range loop

for 走訪任何可迭代物件(iterable);range() 產生數字序列。

for i in range(5):        # 0,1,2,3,4
    print(i)

for i in range(2, 10, 2): # 2,4,6,8
    print(i)

fruits = ["蘋果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)

for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)

while 迴圈 loop

只要條件為 True 就持續執行,常用於次數不確定的重複作業。

n = 5
while n > 0:
    print(n)
    n -= 1
print("發射!")

# 搭配 sentinel 值持續讀取輸入
# while True:
#     cmd = input("> ")
#     if cmd == "exit":
#         break

break / continue / pass control

break 跳出整個迴圈;continue 跳過本次迭代;pass 為空語句佔位。

for i in range(10):
    if i == 3:
        continue     # 跳過3,不印出
    if i == 6:
        break        # 到6就整個結束
    print(i)          # 0 1 2 4 5

def todo():
    pass   # 尚未實作,先佔位避免語法錯誤

三元運算式 control

在單行內完成條件賦值,語法為「值A if 條件 else 值B」。

age = 20
status = "成年" if age >= 18 else "未成年"

# 等同於
if age >= 18:
    status = "成年"
else:
    status = "未成年"

迴圈的 else 子句 loop

for / while 的 else 會在迴圈「正常結束(未被 break)」時執行,常用於搜尋。

nums = [1, 3, 5, 7]

for n in nums:
    if n % 2 == 0:
        print("找到偶數:", n)
        break
else:
    print("沒有偶數")   # 沒被break就會執行

資料結構

List 基本操作 list

list 是有序、可變(mutable)的序列,可放不同型別的元素。

nums = [3, 1, 4, 1, 5]

nums.append(9)        # 尾端新增
nums.insert(0, 0)     # 指定位置插入
nums.remove(1)        # 移除第一個符合的值
nums.pop()             # 移除並回傳最後一個
nums.sort()             # 原地排序
sorted(nums, reverse=True)  # 回傳新的排序 list
len(nums)               # 長度
3 in nums               # 是否存在

List Comprehension list

以簡潔的單行語法建立新 list,取代 for 迴圈 + append。

squares = [x**2 for x in range(10)]
# [0,1,4,9,16,25,36,49,64,81]

evens = [x for x in range(20) if x % 2 == 0]

# 巢狀:攤平二維 list
matrix = [[1,2],[3,4]]
flat = [n for row in matrix for n in row]
# [1, 2, 3, 4]

Tuple tuple

tuple 是有序但不可變(immutable)的序列,常用於固定不變的資料組合。

point = (3, 4)
x, y = point          # 解包

single = (5,)          # 只有一個元素時要加逗號
t = 1, 2, 3             # 括號可省略

def min_max(nums):
    return min(nums), max(nums)   # 回傳 tuple

lo, hi = min_max([4, 2, 9, 1])

Dict 基本操作 dict

dict 儲存 key-value 對應,Python 3.7+ 會保留插入順序。

user = {"name": "Gina", "role": "PM"}

user["email"] = "gina@example.com"  # 新增/更新
user.get("phone", "未提供")          # 安全取值,無key不報錯
del user["role"]                     # 刪除
"name" in user                        # 是否有此key

for key, value in user.items():
    print(key, value)

Dict Comprehension dict

與 list comprehension 相同概念,快速建立字典。

nums = [1, 2, 3, 4]
squared = {n: n**2 for n in nums}
# {1:1, 2:4, 3:9, 4:16}

words = ["apple", "kiwi", "fig"]
lengths = {w: len(w) for w in words if len(w) > 3}
# {'apple': 5}

Set 與集合運算 set

set 是無序、元素不重複的集合,適合去重與集合運算。

a = {1, 2, 3}
b = {2, 3, 4}

a | b     # 聯集 {1,2,3,4}
a & b     # 交集 {2,3}
a - b     # 差集 {1}
a ^ b     # 對稱差集 {1,4}

nums = [1, 1, 2, 3, 3]
unique = set(nums)   # 去重 -> {1,2,3}

序列解包 Unpacking unpack

以 * 收集多餘元素,快速拆解 list / tuple。

first, *rest = [1, 2, 3, 4]
# first=1, rest=[2,3,4]

*init, last = [1, 2, 3, 4]
# init=[1,2,3], last=4

a, (b, c) = (1, (2, 3))   # 巢狀解包

def show(*args, **kwargs):
    print(args, kwargs)
show(1, 2, name="Gina")

函式

定義與呼叫 def

以 def 定義函式,return 回傳結果;沒有 return 則回傳 None。

def greet(name):
    """回傳問候語(這是 docstring)"""
    return f"哈囉, {name}!"

message = greet("Gina")
print(message)

def add(a, b):
    return a + b, a - b   # 一次回傳多個值(其實是tuple)

s, d = add(5, 3)

預設參數與關鍵字引數 def

參數可設定預設值;呼叫時可用「參數名=值」指定,不受順序限制。

def create_user(name, role="member", active=True):
    return {"name": name, "role": role, "active": active}

create_user("Gina")
create_user("Gina", role="admin")
create_user(name="Gina", active=False, role="editor")

# 注意: 預設值不要用可變物件(如 [] 、 {})
# 錯誤示範: def f(data=[]): ...

*args 與 **kwargs def

*args 收集多個位置參數為 tuple;**kwargs 收集多個關鍵字參數為 dict。

def summary(*args, **kwargs):
    print("位置參數:", args)
    print("關鍵字參數:", kwargs)

summary(1, 2, 3, name="Gina", role="PM")
# 位置參數: (1, 2, 3)
# 關鍵字參數: {'name': 'Gina', 'role': 'PM'}

def call_all(func, *args, **kwargs):
    return func(*args, **kwargs)   # 展開呼叫

Lambda 匿名函式 lambda

以 lambda 建立單行、無名稱的函式,常搭配 sorted、map、filter 使用。

square = lambda x: x ** 2
square(5)   # 25

people = [{"name":"Gina","age":28}, {"name":"Amy","age":24}]
people.sort(key=lambda p: p["age"])

add = lambda a, b=10: a + b
add(5)        # 15

作用域 global / nonlocal scope

函式內預設無法修改外部變數,需以 global / nonlocal 明確宣告。

count = 0

def increment():
    global count
    count += 1

def outer():
    total = 0
    def inner():
        nonlocal total
        total += 1
    inner()
    return total

outer()   # 1

遞迴函式 Recursion def

函式呼叫自己來解決問題,務必要有明確的終止條件(base case)。

def factorial(n):
    if n <= 1:          # 終止條件
        return 1
    return n * factorial(n - 1)

factorial(5)   # 120

def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)

物件導向

class 定義與 __init__ class

__init__ 是建構子,在建立物件時自動呼叫,self 代表實例本身。

class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f"{self.name}: 汪!"

d = Dog("小白", 3)
print(d.bark())     # 小白: 汪!
print(d.name)        # 小白

屬性與方法 class

實例屬性存於物件本身;類別屬性由所有實例共享。

class Counter:
    total = 0            # 類別屬性(共享)

    def __init__(self):
        self.value = 0     # 實例屬性(各自獨立)
        Counter.total += 1

    def increment(self):
        self.value += 1
        return self.value

c1, c2 = Counter(), Counter()
Counter.total   # 2

繼承與 super() class

子類別繼承父類別的屬性與方法,super() 用於呼叫父類別的實作。

class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return "..."

class Cat(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 呼叫父類別__init__
        self.breed = breed
    def speak(self):
        return f"{self.name}: 喵~"

Cat("咪咪", "美短").speak()

特殊方法(Dunder) class

以雙底線包圍的方法可自訂物件的內建行為,如印出、比較、長度。

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __repr__(self):
        return f"Point({self.x}, {self.y})"
    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)
    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

Point(1,2) + Point(3,4)   # Point(4, 6)

@property class

讓方法像屬性一樣被存取,可在取值/設值時加入邏輯與驗證。

class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def area(self):
        return 3.14159 * self._radius ** 2

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("半徑不可為負")
        self._radius = value

c = Circle(5)
c.area        # 78.53975(唯讀,無需加括號呼叫)

@staticmethod 與 @classmethod class

staticmethod 不需存取實例或類別;classmethod 接收類別本身(cls)。

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius

    @staticmethod
    def c_to_f(c):
        return c * 9/5 + 32

    @classmethod
    def from_fahrenheit(cls, f):
        return cls((f - 32) * 5/9)

Temperature.c_to_f(100)          # 212.0
t = Temperature.from_fahrenheit(98.6)

多型與方法覆寫 class

不同子類別可對同一方法有不同實作,呼叫時依實際物件型別決定行為。

class Shape:
    def area(self):
        raise NotImplementedError

class Square(Shape):
    def __init__(self, side): self.side = side
    def area(self): return self.side ** 2

class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14159 * self.r ** 2

for shape in [Square(4), Circle(3)]:
    print(shape.area())   # 依實際型別呼叫對應方法

例外處理

try / except / else / finally error

try 區塊出錯時執行 except;else 於「無錯誤」時執行;finally 一定會執行。

try:
    result = 10 / 0
except ZeroDivisionError:
    print("除數不可為零")
else:
    print("計算成功:", result)   # 沒出錯才執行
finally:
    print("清理資源(一定執行)")

攔截多種例外 error

可用 tuple 一次攔截多種例外類型,或用多個 except 分別處理。

try:
    value = int(input("輸入數字: "))
    result = 10 / value
except (ValueError, ZeroDivisionError) as e:
    print("輸入或計算錯誤:", e)
except Exception as e:
    print("其他未預期錯誤:", e)

raise 主動拋出例外 error

可在條件不符合時主動拋出例外,中斷正常流程並提示錯誤原因。

def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("餘額不足")
    return balance - amount

try:
    withdraw(100, 500)
except ValueError as e:
    print("交易失敗:", e)

自訂例外類別 error

繼承 Exception 建立專屬的例外類型,讓錯誤訊息更明確、易於分類處理。

class InsufficientFundsError(Exception):
    """餘額不足時拋出的自訂例外"""
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(f"缺少 {amount - balance} 元")
    return balance - amount

try:
    withdraw(100, 150)
except InsufficientFundsError as e:
    print(e)

檔案與模組

open() 與 with 讀寫檔案 file

使用 with 開檔可確保檔案自動關閉,即使發生例外也不會造成資源洩漏。

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.writelines(["第二行\n", "第三行\n"])

with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()          # 讀取全部
    # 或: for line in f: ...    # 逐行讀取

常見檔案模式 file

open() 第二個參數決定操作模式,常見如下。

# "r"  唯讀(預設,檔案不存在會報錯)
# "w"  寫入(會覆蓋原內容,檔案不存在會建立)
# "a"  附加(在檔案結尾繼續寫入)
# "r+" 讀寫
# "b"  二進位模式,如 "rb"、"wb"

with open("data.bin", "rb") as f:
    raw = f.read()

import 與 from...import module

import 匯入整個模組;from 可只匯入特定成員或使用別名(as)。

import math
math.sqrt(16)          # 4.0

from datetime import datetime
datetime.now()

import numpy as np      # 常見別名慣例
from collections import Counter, defaultdict

if __name__ == "__main__" module

判斷此檔案是「被直接執行」還是「被其他檔案匯入」,常用於放置測試或主程式進入點。

def main():
    print("這是主程式邏輯")

if __name__ == "__main__":
    main()
    # 只有直接執行 python this_file.py 時才會跑
    # 被 import 進其他檔案時不會自動執行

含有 __init__.py 的資料夾會被視為一個套件(package),可用點記法匯入內部模組。

進階語法

裝飾器 Decorator advanced

裝飾器是「接收函式、回傳新函式」的函式,用於在不修改原函式的情況下增加功能。

import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗時 {time.time()-start:.4f}s")
        return result
    return wrapper

@timer
def slow_task():
    time.sleep(1)

slow_task()

生成器 Generator / yield advanced

使用 yield 的函式是生成器,每次呼叫 next() 才會執行到下一個 yield,節省記憶體。

def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up_to(5):
    print(num)   # 1 2 3 4 5

gen = (x**2 for x in range(5))  # 生成器表達式
next(gen)   # 0
next(gen)   # 1

迭代器協定 Iterator advanced

實作 __iter__ 與 __next__ 即為自訂迭代器,for 迴圈底層即依此協定運作。

class Countdown:
    def __init__(self, start):
        self.current = start
    def __iter__(self):
        return self
    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

for n in Countdown(3):
    print(n)   # 3 2 1

Context Manager (with) advanced

實作 __enter__ / __exit__ 即可自訂 with 語法的行為,常用於資源的取得與釋放。

class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        print(f"耗時 {time.time()-self.start:.4f}s")

with Timer():
    total = sum(range(1_000_000))

# 也可用 contextlib.contextmanager 以生成器實作

map / filter / reduce functional

函數式風格的三劍客:map 轉換、filter 篩選、reduce 累積運算。

from functools import reduce

nums = [1, 2, 3, 4, 5]

list(map(lambda x: x*2, nums))       # [2,4,6,8,10]
list(filter(lambda x: x%2==0, nums)) # [2,4]
reduce(lambda a,b: a+b, nums)         # 15(累加)

# 多數情況 list comprehension 更易讀:
[x*2 for x in nums if x%2==0]

正則表達式 re 模組 regex

使用正則表達式(regex)比對、搜尋、取代字串樣式,原始字串前綴 r 可避免跳脫字元困擾。

import re

text = "聯絡我: gina@example.com 或 02-1234-5678"

re.search(r"\w+@\w+\.\w+", text).group()   # 'gina@example.com'
re.findall(r"\d{2}-\d{4}-\d{4}", text)       # ['02-1234-5678']

enumerate / zip / sorted 進階 builtin

names = ["Amy", "Bob", "Cindy"]
scores = [88, 92, 79]

for i, name in enumerate(names, start=1):
    print(i, name)

for name, score in zip(names, scores):
    print(name, score)

ranked = sorted(zip(names, scores), key=lambda p: -p[1])
# 依分數由高到低排序: [('Bob',92), ('Amy',88), ('Cindy',79)]
