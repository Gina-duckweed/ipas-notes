SVM
支援向量機

用途：分類（二元 / 多類別）、迴歸（SVR）

目標：找到讓兩類資料之間「安全距離（margin）」最大的決策超平面。

白話理解
💡 把兩類資料想像成兩群人，SVM 找到一條 「最寬走廊」把他們分開。
走廊邊緣，最靠近中線的點叫 支援向量，它們決定了走廊的位置與寬度。
遇到非線性問題時，用 核函數把資料映射到更高維的空間再分割。
圖像示意
數學表達式
決策：f(x) = wᵀx + b
目標：最大化 margin = 2 / ‖w‖
等效：最小化 ½‖w‖²（帶約束）
核：K(xᵢ,xⱼ) = φ(xᵢ)ᵀφ(xⱼ)
• w：法向量  |  b：截距  |  C：懲罰參數（軟間隔）

核函數比較（Kernel Functions）
核函數 公式 適用情境 常用程度
Linear xᵢᵀxⱼ 線性可分、文字分類 ⭐⭐
RBF / Gaussian exp(−γ‖xᵢ−xⱼ‖²) 非線性、通用首選 ⭐⭐⭐ 最常用
Polynomial (γxᵢᵀxⱼ + r)ᵈ 多項式決策邊界 ⭐⭐
Sigmoid tanh(γxᵢᵀxⱼ + r) 類神經網路行為 ⭐
優點
  • 高維空間效果優秀（文字、基因）
  • 核技巧靈活處理非線性邊界
  • Soft Margin 對離群值有抵抗力
  • 僅依賴支援向量，記憶效率高
缺點
  • 大資料集訓練非常慢（O(n²)~O(n³)）
  • 參數 C 與核參數（如 γ）選擇敏感
  • 輸出非機率，需 Platt Scaling 轉換
  • 對特徵縮放高度敏感
🔍 考試關鍵字
  • 超平面（Hyperplane）、法向量 w
  • 支援向量（Support Vector）
  • 間隔最大化（Margin Maximization）
  • 核函數 / Kernel Trick
  • 軟間隔 / Soft Margin / 參數 C
  • 對偶問題（Dual Problem）/ KKT 條件
⭐ 什麼情境適合用？
  • 高維小樣本（文字、基因、影像特徵）
  • 特徵數量遠多於樣本數
  • 需要非線性分類邊界（用 RBF 核）
  • 二元分類問題（多類用 One-vs-One）
  • 訓練資料量不超過十萬筆
小提醒 使用 SVM 前，記得檢查：
  1. 特徵縮放（StandardScaler）是必須的，SVM 對尺度極敏感！
  2. 參數 C（越大 → 允許更少誤分 → 容易 Overfitting）
  3. RBF 的 γ（越大 → 決策邊界越複雜 → 容易 Overfitting）
  4. 多類別問題預設使用 One-vs-One 策略。
